# 学習要求の記録と保有モデルの共同学習

再開案内の候補「標本1件の処理の残り」のうち、学習要求の記録と共同学習の接続を切り出す。

- 本spec: 学習要求を1件記録して、保留が更新間隔に達したら保留中の全要求のぶんを共同学習する関数（旧`train_step`）と、保留中の要求を間隔に関係なく学習する関数（旧`flush_pending_updates`）。どちらも、完了した学習量をモデル別の計数へ反映してから保留を消化する。学習要求の件数管理へ、間隔に達したかを読む操作を1つ足す。
- 後続: 標本1件の処理全体（これらの関数をどの位置で呼ぶか。警報の前の消化、ラウンド境界の消化）、保留標本そのものを持つowner、計算量・時間・勾配の診断。

既存の学習要求の件数管理・共同学習の反復・計数の中の処理は変えない。固定旧`748c3aa`とgoldenは変更しない。アルゴリズムの変更はしない。
