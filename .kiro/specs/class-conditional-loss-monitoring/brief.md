# 背景と境界候補

研究者が最終提案のClassESR損失監視を、モデル・学習・候補処理に依存せず旧実装と同じ数値と警報位置で確認できるようにする。予測重みと混合予測の数値部品は既に移植済みだが、監視は旧clientに組み込まれている。

Boundary Candidatesは単一損失系列のe-SR、全体/正解クラス系列の混合、モデル統計からのbaseline選択、FIFOへの位置受渡しである。今回は前2者と、外部指定baseline・global位置を受け取る契約を対象にする。モデル統計の蓄積・FIFOによる位置切詰め・警報後操作は後続specの責務として保持する。

現行モデルの観測後有界損失・正解クラス・標本位置を入力し、全体成分と該当クラス成分だけを更新する。等重みの混合値・警報・候補開始位置・計算件数を返す。旧baselineの下限は呼出し側による0.01で、検出器の数値安全域とは区別する。baselineは外部から渡し、全体は初期/reset時、各classは初観測時に固定する。

要件・設計・命名・task・実装の承認はユーザー委任どおりLunaレビューと主担当の有用指摘反映で進める。旧productionとgoldenは748c3aaを基準に変更しない。今回の完成を新FedSDA全体runの完成とは扱わない。
