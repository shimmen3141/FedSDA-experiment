# 目的と境界候補

研究者が最終FedSDAの候補採否を旧実装と同じ損失・比較対象・結果で検証できるよう、clientに埋め込まれた警報後損失による既存モデル再利用と候補の二分区間判定を独立した部品へ移植する。

Boundary Candidatesは将来損失の収集、既存モデルの履歴平均との差による再利用適合性、比較対象選択、二分区間の候補優位判定、確定後の登録・割当である。
今回は外部で収集を完了した有界損失列を入力として、再利用適合性・比較対象選択・候補判定と診断値だけを所有する。モデルforward・snapshot生成・学習・収集session・警報後の実モデル操作・FIFO・client調整は後続の責務。
既存設定の最終採否方針と検証件数を用いる。代替policyの再実装は今回の対象ではない。正常入力は旧forward_persistentへ直接照合し、不正入力は明示拒否する。
命名と各段階の承認はユーザー委任によるLunaレビューと主担当の有用指摘反映で進める。
