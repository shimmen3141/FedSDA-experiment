# 警報区間でのモデル再利用評価 — 要求 revision2

研究者が旧挙動を維持して警報処理を組み立てるため、切出し済みの非空変化区間に対して保有モデルを評価し、再利用先と候補初期値選択に必要な評価情報を得られるようにする。

前区間処理済みの統計と保有状態を使用する。区間取得/最小区間件数による開始可否、評価標本保存/吸収、帰属変更、候補生成/学習/session開始、active session/episode/FIFO/通知/一覧/計算量診断、新client/全runは範囲外。並行更新・非公開状態改変・OOM/overflowは保証外。新実装の対象は既存のCPU float32二値/多クラス分類器。

## 1. 区間損失と履歴基準

- 1.1 When 非空の変化区間の評価を要求されたとき、the Alarm Interval Reuse Assessment shall 保有順に全モデルの標本別損失の区間平均を評価し、現在の全体履歴が2件以上で平均が非零のモデルだけを同じ順序で評価済み候補に含める。履歴なし・0件・1件・零平均のモデルも区間評価を行うが、初期値選択用の評価済み候補へは含めない。
- 1.2 When 履歴基準を利用できるモデルを判定するとき、the Alarm Interval Reuse Assessment shall 区間平均損失から履歴平均損失を引いた値が指定の許容損失増加量以下なら再利用可能候補とする。閾値と等しい場合も適合し、区間平均が履歴より低い場合も同じ式で判定する。

## 2. 選択と状態保持

- 2.1 When 再利用先を返すとき、the Alarm Interval Reuse Assessment shall 再利用可能候補の区間平均が最小のIDを選び、同率では保有順を使い、候補なしでは再利用先なしを返す。現行モデルやIDの大小を優先しない。負の一時IDも正のIDと同じ規則で扱う。
- 2.2 When 評価情報を返すとき、the Alarm Interval Reuse Assessment shall 評価済み候補と再利用可能候補のID/区間平均列と選択IDを変更不能な記録で返し、モデルparameter/grad/optimizer・履歴統計・保有順・学習標本・帰属・乱数状態を変更しない。候補が空の場合も空列と選択なしを保持する。

## 3. 拒否と回帰証拠

- 3.1 If 入力が不正なとき、the Alarm Interval Reuse Assessment shall 状態と乱数を変更せず例外で拒否する。不正は状態所有者の型違い、保有モデルなし、非数値/bool/非有限/負の許容損失増加量、既存分類器の区間評価契約に反する特徴/ラベルの型・形状・値・環境を含む。型違いはTypeError、値違いはValueErrorで区別する。
- 3.2 When 本評価を実行するとき、the Alarm Interval Reuse Assessment shall 同じ基準環境の実旧と評価平均・候補順序・適合判定・同率選択・状態/乱数を同じ値にする。2/4クラス、単一/複数モデル、欠損/0/1/2件以上/零履歴、同率、適合なし/現行以外の適合、負ID、閾値の直前/等値/直後を対照する。平均は旧と同じ演算精度で算出し、環境差を理由にgoldenを更新しない。
