# 要件: サーバ向けのクライアント損失平均集約
## Boundary Context
一モデルについて、参加クライアントの全体損失統計からサーバが配布する件数・加重平均を計算する。
モデルを所有し、そのモデルの学習データ件数が正で、統計があるクライアントを上位が登録順に選別する。
学習データ件数は参加条件であり、損失平均の重みは統計の観測件数。モデルパラメータ集約や通信は含めない。
サーバ統計の保存/ID/クラス情報の扱い、参加判定、モデル操作、候補進行・新全体runは上位の責務。
統計全体の分散を合成する機能ではなく、旧サーバの件数・平均・偏差平方和ゼロの方針を保持する。

## 入力契約
入力は上位が選別した、参加クライアント順の既存有界損失集計。空入力とゼロ件集計を許す。
各件数・平均・偏差平方和は既存集計型の契約に従い、暗黙変換しない。
入力全体と算出結果を検査し、非有限/表現不能/契約範囲外の結果は補正せず拒否する。

## Requirements
### Requirement 1: 件数で加重する損失平均
1. When 参加クライアントの集計を受ける, the Server Loss Mean Aggregator shall 入力順に平均と観測件数の積を加算し、観測件数を合計して、その合計を重みとして旧演算順の平均を計算する。
2. While 合計観測件数が正である, the Server Loss Mean Aggregator shall 合計件数・加重平均・偏差平方和ゼロの全体集計を返し、入力の分散やクラス情報を合成しない。
3. While 入力が空または合計件数がゼロである, the Server Loss Mean Aggregator shall 更新なしを示す結果を返し、既存サーバ統計を暗黙に初期化・消去しない。

### Requirement 2: 入力拒否と独立性
1. If 入力型・要素・集計値または算出結果が契約に反する, the Server Loss Mean Aggregator shall 項目名と理由を示して拒否し、後段の無効要素も見逃さず入力を変更しない。
2. The Server Loss Mean Aggregator shall 入力・別呼出の結果と独立した変更不能な集計を返す。
3. The Server Loss Mean Aggregator shall 共有乱数・勾配状態・既定数値環境を変更しない。

### Requirement 3: 移植・明示接続
1. The Server Loss Mean Aggregator shall 参加/不参加・欠落・ゼロ・異なる学習量・入力順を含め、旧通常サーバと最終構成の共有バックボーンサーバの件数・平均・偏差平方和へ直接照合できる。
2. The Server Loss Mean Aggregator shall 更新なしでは既存サーバ統計を保持し、更新ありではクラス情報を空にしてサーバ統計へ保存・ID対応後の補完・帰属更新・基準値選択へ明示接続でき、これらを暗黙に実行しない。
3. The Server Loss Mean Aggregator shall 旧import/aliasなしで独立起動でき、既存golden不変と完成範囲・実測した発見事項を記録する。
