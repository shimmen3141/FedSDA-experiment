# 保留学習データの位置・FIFO管理spec

正本はspec.json（段階/承認）→requirements.md（契約）→design.md（責務/API）→naming.md（正式名/revision）→tasks.md（実装順）。
brief.mdは範囲、research.mdは旧調査、review.mdは採否/承認、integration-validation.mdは実行証拠。未生成文書は未完了段階。
