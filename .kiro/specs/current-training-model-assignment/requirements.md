# 要求 revision 3

## 1. 単一の帰属ID

- 1.1 When 明示的な初期モデルIDでownerを生成したとき, the owner shall 現在の学習帰属モデルIDを読取り専用で公開する。IDは負の一時IDを含むbuiltin intのみとし、bool・int派生型・暗黙変換を受理しない。
- 1.2 When 上位が選択したIDを設定したとき, the owner shall 異なる場合だけ以前と現在のIDを含む不変の変更記録を返す。同じIDではNoneを返す。新規作成・再利用・登録確認の判断は上位が行う。

## 2. サーバ対応表

- 2.1 When 対応表を受け取ったとき, the owner shall builtin dict[int,int]全項目を先に検証し、現在IDに一段だけ対応表を適用する。連鎖をたどらず、対応の欠落・自己対応・空dictは変更なしとする。実変更時の返り値は1.2と同じ。
- 2.2 If 入力が不正なら, the owner shall TypeErrorを返し、現在IDを更新しない。現在IDに無関係な不正項目も拒否する。入力dictを保存・変更しない。

## 3. 分離と移植検証

- 3.1 The owner shall モデルの存在・採番・統計・標本・計数・予測混合重み・送信待機・イベント・乱数を所有しない。変更記録も理由や時刻を持たず、上位が必要な通知や記録を行う。
- 3.2 When 旧と新へ同じ有効な切替え・対応表を適用したとき, the new API shall 実旧FedSDAのローカル切替えとBaseClientのサーバ対応表適用のID変更を維持する。登録確認時の単一ID変更も計数移管と区別する。変更理由別の通知は上位で区別し、ownerから自動通知しない。
- 3.3 When 現在IDを変更したとき, the owner shall 他ownerのモデル・統計・標本・計数・送信待機を変更しない。返した変更記録は後続の現在ID変更によって変化しない。
