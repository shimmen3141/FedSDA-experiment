# 命名

Pythonの公開API追加はない。単独HTMLのscriptはIIFE内に閉じ、公開JS APIも設けない。naming検査のsource対象は追加なし。

| 表示名 | 意味・区別 |
|---|---|
| 現行モデル | 学習標本の帰属と局所損失監視の対象。予測の最大重みモデルとは別 |
| モデル別重み | 保有モデルの予測を結合するFixed-Share重み。同期・局所両レーンで共用 |
| 同期・局所の重み | 二つの結合予測を混ぜる別の重み。モデル別重みと混同しない |
| 帰属待ちFIFO | 学習ストアへの帰属を待つ標本。検証sessionや確定済みストアとは別 |
| 固定参照 | 警報時点の既存モデルの写し。同期時点の予測用の写しとは別 |
| 候補 | 採否未確定の学習中モデル。採用後に保有モデル・登録待ちへ進む |
| 時間尺度T | モデル重みと二者の分け合いに共通。FIFO容量と独立 |
