# FedSDAの既存モデル再利用方針

FedSDAはドリフトを検出すると、FIFO内の推定新概念データで全保持モデルを評価する。
モデルの平均損失と履歴平均の差が `FEDSDA_DISTANCE_THRESHOLD` 以下なら、そのモデルを
現在の概念へ適合する既存モデルとみなす。

適合モデルが複数ある場合の選択は `FEDSDA_MODEL_REUSE_POLICY` で指定する。

## best_fit

適合モデルのうち、FIFO上の平均損失が最小のモデルを選ぶ従来方式である。現行モデルも
適合していても、別モデルの損失が小さければ切り替える。既定値であり、既存実験の結果を
変更しない。

## current_first

次の順序で選択する。

1. 現行モデルが適合していれば維持する。
2. 現行モデルが不適合なら、適合する別モデルのうち平均損失が最小のものへ切り替える。
3. 適合モデルがなければ、設定された新規モデル作成方針へ進む。

現行モデルにヒステリシスを持たせるため、僅かな損失差による不要な切替を抑えられる。
新しい数値ハイパーパラメータは追加しない。一方、より良い既存モデルへの切替を遅らせ、
recallやaccuracyを下げる可能性があるため、`best_fit` と実験で比較する。

## 新規モデル作成方針との関係

この設定は、ドリフト検出直後の最初の既存モデル評価にだけ作用する。
`forward_requalified_current_first` は、既存モデルが最初の評価で一つも適合せず、
仮モデルの前向き検証へ進んだ後の再適合判定に作用する。両者は独立して選択できる。

## 診断値

Pareto CSVには次の件数を保存する。

- `model_reuse_current_fit_count`: 最初の既存モデル評価で現行モデルを選んだ件数
- `model_reuse_alternative_fit_count`: 最初の既存モデル評価で別モデルを選んだ件数

CSVの `model_reuse_policy` とraw NPZの同名メタデータには、実験で使用した方針を保存する。
