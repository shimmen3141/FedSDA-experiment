[手法比較](method-comparison-recurring-synthetic-v16-20261120.md)で、変化の直後を除く安定した期間の精度が、6セル中5セルでFedDrift（既定のδ0.10）より低かった。その原因を切り分ける（ユーザーの依頼）。

## まとめ（数値をそのまま述べる）
- 間隔500では、安定した期間の差はほぼ全部が割り当ての誤り（誤った警報と、それによる学習の分断・誤った再利用）から来る。真の概念で割り当てればFedDriftと同じ水準（−0.1pp）になる。
- 間隔50では、割り当ての誤りが差の約半分（55〜58%、stagger3は49%）を説明し、真の概念で割り当てても0.5〜2.5ppの差が残る。残りは、割り当てとは別の要因（学び方の違い: FedHASPは標本を1件ずつ1回学び、FedDriftはラウンドごとにまとめて学ぶ。集約が頻繁なほどFedDriftの学習量が増える）と見られるが、切り分けていない。
- この3データの特徴（Agrawalの摂動の雑音、Random RBFの重なり）で、損失の監視が誤った警報を出しやすい。元の10データでは安定した期間でもFedHASPが上だったので、データの性質に依存する。

## 3. データの性質（2026-11-20、主担当、手元の短い測定）
製品の生成器で各概念の標本を作り、FedHASPと同じ形のMLP（隠れ層32・32、Adam（amsgrad）、学習率0.01、weight decay 0.001、1回の更新32標本）を、概念ごとに別々に学ばせた。評価は各概念5,000標本（seedは学習と別）。runの中の学び方とは違う（予測の混合・集約・事前学習なし）ので、データの性質の比較として使う。

| データ | 上限（2万標本×20回） | 250標本 1回 / 10回 | 1,000標本 1回 / 10回 | 別の概念のモデルの精度（平均、最小〜最大） |
|---|---|---|---|---|
| sine2 | 99.4 | 77.6 / 97.2 | 97.0 / 98.7 | 0.7 |
| circle2 | 98.4 | 86.4 / 95.4 | 86.4 / 97.6 | 73.6（72.1〜75.1） |
| sea4 | 88.9 | 72.2 / 79.7 | 76.6 / 84.4 | 80.0（71.1〜87.5） |
| stagger3 | 100.0 | 77.3 / 100.0 | 93.7 / 100.0 | 38.3（21.4〜52.1） |
| agrawal4 | 92.2 | 59.3 / 74.4 | 65.4 / 87.5 | 52.7（44.5〜77.2） |
| randomrbf4 | 93.6 | 59.1 / 80.8 | 70.1 / 87.8 | 45.9（36.7〜55.5） |

- agrawal4とrandomrbf4は、1,000標本を1回学んでも上限より22〜27pp低く、同じ標本を繰り返して学ぶと大きく上がる（学ぶのに多くの標本・回数が要る）。ほかのデータは、1,000標本を1回で上限の3〜12pp以内（circle2は多数派の予測に留まる例外）。
- 概念どうしは大きく違う（別の概念のモデルでは当たらない）ので、概念を取り違えると損が大きい。agrawal4には似た概念の組もある（最大77.2）。
- 安定した期間のFedDriftの精度（agrawal4 89.6、randomrbf4 91.2、間隔50）は、「繰り返して学んだ」水準に近い。
