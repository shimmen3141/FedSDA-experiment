# モデルの集まりで混ぜる予測と共有の、定理の形と証明の概略（2026-11-24、主担当）

- 目的（ユーザーの依頼、2026-11-24）: 外部の指摘「エキスパート統合が本質か。選んだ1モデル（固い予測）で同程度以上ができるのでは」に、単純化した設定での保証で答える。[実験の記録](linear-concept-pool-theory-20261124.md)の1〜3章で形を確かめた見通しを、仮定・主張・証明の概略として書く。
- 位置づけ: 証明は主担当が書いた概略で、独立の確認（別の担当による検算）はしていない。既知の結果（Fixed Share、Laurent–Massartの不等式、最小二乗の超過リスク）は文献の主張をそのまま使い、新しいのは組合せ方と、FedHASPの仕組みへの対応付けである。文献の正確な定数・条件は、論文に書く前に原典で確かめる必要がある（未確認）。

## 0. 設定と記号

- client m = 1..M、時刻 t = 1..T。各clientの真の概念 c_{m,t} ∈ {1..K} は区分的に一定で、切り替えの回数は S_m。
- 入力 x ~ N(0, I_d)、ラベル y = ⟨θ*_c, x⟩ + ξ（ξは平均0・分散σ²）。概念の違い Δ := min_{c≠c'} ||θ*_c − θ*_{c'}||²。
- モデルの集まり: 時刻tにclientが持つモデルの集合 N_{m,t}。各モデルkは係数 θ_{k,t} を持ち、時刻tのラベルを見る前に決まる（過去の標本だけで学習する）。モデルkが表す概念を κ(k)（学習の標本の多数派）とする。ここまでに作られたモデルの総数をNとする。
- 損失 ℓ(ŷ, y) = (ŷ − y)²。予測とラベルが [−B, B] に入るとき（ラベルは切り詰める）、ℓ は η-exp-concave（η = 1/(8B²)）。
- 予測の方式: 固い予測 p^hard_t = f_{a_t}(x_t)（a_t は割り当てたモデル）、混合 p^mix_t（N_{m,t}のFixed Share）、比べる相手 p^orc_t = f_{k*_t}(x_t)（k*_t は概念c_tを表す保有モデル。無ければ a_t）。
- 記号 R(S, N, T) := (1/η)[(S+1) ln N + S ln(e(T−1)/S)]（Fixed Shareの、切り替えS回の列に対する後悔の上界の形。α = S/(T−1) のとき）。

## 1. 定理1（混合は、固い予測とoracleの良い方に、対数の費用で追いつく）

**仮定**: 損失は η-exp-concave。混合はFixed Share（共有率 α）で、まだ作られていないモデルは「予測を混合と同じにする」（specialistの扱い。Freund ら1997）。統合されたモデルは、統合の先と同じ予測をするとみなす。

**主張**: 任意の系列で、clientごとに
L^mix ≤ min{ L^hard + R(S^a, N, T),  L^orc + R(S, N, T) } ＋（αの選び方による差）。
ここで L は累積損失、S^a は固い予測の割り当て a_t の切り替えの回数（重複したモデルの間の行き来も数える）、S は真の概念の切り替えの回数。

**証明の概略**: Fixed Shareの保証（Herbster & Warmuth 1998）は、各時刻にラベルの前に決まる任意の予測の列（エキスパート）に対し、「S回だけ切り替えるエキスパートの列」の累積損失との差を R(S, N, T) で抑える。エキスパートの予測は過去に依存してよいので、学習の途中のモデルでよい。a_t の列と k*_t の列は、どちらも各時刻に保有するモデルを選ぶ列なので、比べる相手に取れる。統合は「jがその後iと同じ予測をする」ことと同じで、重みの和（実装の logaddexp）は2つのエキスパートの重みを足すことに当たり、保証を変えない。まだ無いモデルをspecialistとして扱えば、Nは作られたモデルの総数でよい。

**意味**: 混合の予測は、割り当ての誤り・遅れ・重複がどれだけあっても、固い予測より R(S^a, N, T) を超えて悪くならず、同時に、真の概念のモデルの列にも R(S, N, T) で追いつく。重複したモデルの費用は ln N でしか増えない（実験3章の「混合は重複に強い」の説明）。

**限定**: 保証は η ≤ 1/(8B²) で成り立つ。実験で調整した混合の学習率は s≥1 でこれより大きく、実測の切り替え1回あたりの費用は、保証の式に選んだηと共有率を入れた値の0.11〜1.91倍で、定数は合わない（`results/linear-concept-pool/20261124_controlled-assignment-v1`から計算。理論値のηでは上界は成り立つが、実測より桁で大きい）。実装は新しいモデルを重み α/保有数 で入れるので、specialistの扱いと同じではない。

## 2. 命題2（固い予測が払う費用）と系（入れ替わりの条件）

**仮定**: 各時刻、全モデルが自分の概念でε程度に学習できている: ||θ_{k,t} − θ*_{κ(k)}||² ≤ ε。

**主張**: n^wrong := #{t : κ(a_t) ≠ c_t}（割り当てたモデルの概念が真の概念と違う標本の数。同じ概念の重複は数えない）として、
E[L^hard] − E[L^orc] ≥ (Δ − 2√(Δε)) · E[n^wrong]。

**証明の概略**: 入力が等方の正規分布なら、過去を条件として E[(⟨θ, x⟩ − y)²] = σ² + ||θ − θ*_c||²。κ(a) ≠ c なら三角不等式で ||θ_a − θ*_c|| ≥ √Δ − √ε、また ||θ_{k*} − θ*_c||² ≤ ε なので、1標本の期待損失の差は (√Δ − √ε)² − ε = Δ − 2√(Δε) 以上。時刻ごとの条件付き期待値を足す。

**系（入れ替わり）**: 定理1と合わせると、(Δ − 2√(Δε)) · E[n^wrong] > R(S, N, T) なら E[L^mix] < E[L^hard]。検出の遅れが切り替えごとにd件なら n^wrong ≥ S·d なので、**d > R(S, N, T)/(S(Δ − 2√(Δε))) ≈ (ln N + ln(eT/S))/(ηΔ) を超える遅れで混合が勝つ**。逆に、遅れも誤りも無ければ（n^wrong = 0）、固い予測はoracleと一致し、混合は最大 R(S, N, T) だけ悪くなりうる（この上界は、混合が必ず悪いことは示さない。実験では遅れ0・誤り0の9 cellすべてで混合が悪かった）。

**実験との対応**: 2章で、混合が上回る最小の遅れは、実測の費用Cから予測した d* = C/(2s²) とs=1・3で合った（Δ = 2s²）。保証の形（費用はΔに反比例）と合うが、Cは保証の値ではなく実測を使った。

**限定**: ε-精度の仮定は、学習の途中（新しいモデルの学び始め、汚れたモデル）では成り立たない。その期間を除いて足すか、εを時刻ごとに置き換える必要がある（未整理）。

## 3. 補題3（誤った学習による汚れ）

**主張**: 最小二乗（経験リスク最小化、等方の入力）で、モデルが概念cの標本と、割合ρで概念jの標本から学ぶと、標本が多い極限の係数は (1−ρ)θ*_c + ρθ*_j で、概念cでの余分な損失は ρ²||θ*_c − θ*_j||²。

**証明の概略**: 共分散が同じ2つの分布の混合の母集団の最小二乗解は、各概念の解の重み付き平均。概念cの損失の余分は係数の差の2乗。

**意味**: 遅れdの汚れは ρ ≈ d/I なので、固い予測の予測の費用（命題2、ρの1乗）より小さい（ρの2乗）。共有では、モデルIDごとに全clientの標本で学ぶので、ρは全clientの誤った学習の割合になる。他のclientの誤りが自分のモデルを汚す（実験3章の、全体で初めての区間で共有が悪化した結果の説明の候補）。SGD（実験の学習）は最近の標本に重みを置くので、ρの実効値は区間の中で変わる（未整理）。

## 4. 命題4（窓の検定で概念を分けられる条件。IFCAの補題に当たる）

**仮定**: 窓のw件は同じ概念cから独立に来て、窓の間はモデルを固定とみなす。モデルkの残差の分散を v_k := σ² + ||θ_k − θ*_c||²（正規の入力と雑音なら、残差は N(0, v_k)、窓の平均損失は v_k·χ²_w/w）。

**主張**:
- (a) 正しいモデルを選ぶ: 正しいモデルkと別の概念のモデルjの差 g := v_j − v_k > 0 について、P(窓の平均損失で j が k 以下) ≤ 2 exp(−w g²/(25 v_j²))。保有モデルについて和を取ると、選び間違いの確率は 2(N−1) exp(−w g_min²/(25 v_max²)) 以下。
- (b) まとまる条件: 新しいモデルを作る閾値を τ = σ²(1 + z√(2/w)) とする。概念cのモデルがまだ無く、今のモデルjが別の概念のとき、v_j(1 + 2√(u/w) + 2u/w) ≤ τ なら、確率 1 − e^{−u} 以上で j が閾値を通り、新しいモデルは作られない（cはjにまとまる）。Δ ≪ σ² のとき、これはおおよそ **w ≲ 2z²σ⁴/Δ²** のとき起こる。逆に、概念を分けるには w ≳ 2z²σ⁴/Δ² が要る。

**証明の概略**: Laurent–Massart（2000）の不等式 P(χ²_w ≥ w + 2√(wu) + 2u) ≤ e^{−u}、P(χ²_w ≤ w − 2√(wu)) ≤ e^{−u} を使う。(a) は ρ := √(u/w) ≤ 1/2 として、v_k(1 + 3ρ) ≤ v_j(1 − 2ρ) となる ρ = g/(5v_j) を取り、2つの片側の事象の和で抑える（同じ窓の標本なので2つの平均損失は相関するが、和の上界には影響しない）。(b) は上側の不等式をそのまま使い、v_j ≈ σ² + Δ を代入して展開する。

**実験との対応**: 3章で、s=0.5（Δ = 0.5、z = 3 で予測 w* ≈ 72）の誤った学習の割合は、w = 10・30・100 で 0.314・0.100・0.020 と、予測の付近で下がった。s=0.3（予測 ≈ 556）では w ≤ 100 でまとまり、w = 300 で分かれ始めた（予測より早い。(b) は十分条件側の粗い評価のため）。agrawal4の概念1と3がまとまった現象（神経網）は、(b) の形（概念の違いが窓の雑音に比べて小さい）と合う。FedHASPのMDLは閾値τの代わりに符号長の差を使うが、まとまる条件の形（窓の長さと概念の違いの2乗の積）は同じと見込む（未確認）。

**限定**: 窓の中で概念が変わる場合（変化の直後）と、モデルが窓の間に動く場合は扱っていない。遅れ（実験の予測P2）はこの命題では決まらず、実験では「再利用の前に重複を作る」動きのために、単純な予測が外れた。

## 5. 命題5（共有の効果）

**仮定**: 最小二乗（経験リスク最小化、等方の正規の入力）で、割り当ては正しい（汚れなし）。共有では、概念kのモデルは全clientの標本 n_k = Σ_m n_{m,k} で学び、同期の遅れは無視する。

**主張**: n ≥ d + 2 件で学んだ最小二乗の期待の超過損失は σ²d/(n − d − 1)。clientmが時刻τに初めて概念kに出会い、その後 n_0 件をその概念で処理するとき、
- 共有なし（自分の標本だけ）: 期待の累積超過損失 ≈ B_0·(d+1) + σ²d·ln(n_0)（B_0 は学び始めのd+1件の損失の上限の程度）
- 共有あり: ≈ σ²d·ln((n_k(τ) + n_0)/n_k(τ))
で、他のclientがすでに多く学んでいる（n_k(τ) が大きい）ほど、共有の利得は大きい。全体で初めての概念（n_k(τ) = 0）では差が無い。

**証明の概略**: 最小二乗の超過リスクの期待値の式（正規の入力のWishart行列の逆行列の期待値）を、標本1件ごとに足す。

**意味**: 共有の利得は「自分には初めてで、他のclientが経験済み」の区間に集中する（実験1・3章で確認）。定理1の比べる相手は保有モデルの列なので、共有で学習済みのモデルが集まりに入れば、遅れや誤りがあっても、混合はそのモデルの損失に R の費用で追いつく。(a) 他のclientの経験と (b) 遅れ・誤りの補償は、この形でつながる。固い予測は、正しいモデルへ割り当てるまで共有の利得を受け取れない（命題2の n^wrong の間）。

**限定**: SGDの1回ずつの学習（実験）や神経網には、この式はそのまま当てはまらない。汚れがあると補題3の項が加わり、共有で他のclientの汚れも入る。

## 6. まとめと、FedHASPへの対応

| 主張 | 指摘への答え | 実験での確認 | 残る穴 |
|---|---|---|---|
| 定理1: 混合 ≤ min(固い＋R(S^a), oracle＋R(S)) | 混合は「選んだ1モデル」の良さを対数の費用で保ちつつ、選択の誤り・遅れ・重複を補う | 推定の割り当てで96/96 cell混合が上 | 調整したηでは保証の条件の外。定数は合わない |
| 系2: 遅れ d > (ln N + ln(eT/S))/(ηΔ) で混合が勝つ。遅れ・誤り0なら固い予測が良い | 割り当てが正しく速ければ、指摘のとおり固い予測が良い | 制御した実験で入れ替わりの位置が d* = C/(2s²) と合う（s=1・3） | εの仮定は学び始めで崩れる |
| 補題3: 汚れはρ²Δ | 遅れの学習への害は、予測への害より小さい | 真の概念のモデルも遅れで悪化（2章） | SGDでのρの実効値 |
| 命題4: 分けるには w ≳ σ⁴/Δ²、満たさないとまとまる | 似た概念はまとまり、そのとき単一モデルと同等 | s=0.5で予測の付近に境 | MDLへの置き換え、窓の中の変化 |
| 命題5: 共有の利得は他のclientが経験済みの概念に集中 | 連合学習で効果が大きい理由の1つ | 区間の種類ごとの集計で集中を確認 | 汚れの共有、SGD |

- 説明できていないこと: 神経網のFedHASPでは、変化の無い時期でも柔らかい予測が1.4〜2.6pp上で、その多くは同期と手元の2つの版の混合（+1.6pp）による。上の定理は、変化（切り替え）に伴う費用だけを扱い、この「版の混合による分散の低減」を説明しない。別の命題（例: SGDの2つの反復の平均で分散が下がる）が要る（未着手）。
