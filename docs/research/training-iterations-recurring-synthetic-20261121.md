# 保有モデルの学習の量を増やす（2026-11-21）

ユーザーの依頼（2026-11-21）: 割り当てを正しくしても残るFedDriftとの差（[安定した期間の差の切り分け](stable-period-gap-recurring-synthetic-20261120.md)、間隔50で0.5〜2.5pp）が、学び方から来るかを、保有モデルを繰り返し学ぶ量を増やして小さく確かめる。

## 今の学び方（コードで確かめた）
- FedHASPの既定: 観測標本1件の学習要求ごとに、そのモデルの保管標本（上限なし）から最大32件を抜き出して、1回更新する（`fedsda_final_configuration_run_settings._JOINT_UPDATE_ITERATIONS_PER_TRAINING_REQUEST`=1、batch 32）。そのため、過去の標本はすでに繰り返し使われている。[安定した期間の差の切り分け](stable-period-gap-recurring-synthetic-20261120.md)のまとめに書いた「FedHASPは標本を1件ずつ1回学ぶ」は不正確だった。
- FedDriftの既定: 標本1件あたり1回の更新、batch 32（`feddrift_default_run_settings`の`updates_per_sample=1`、`local_training_batch_sample_count=32`）。学習の量は、FedHASPの既定と同じ。表のclient MACも同じくらい（0.020〜0.023 と 0.017〜0.021）。

## 条件
- 研究ツール`tools/research_training_iterations`（commit `36c9f1a7`、基準版16、手元のWindows、14 workers）。上の定数だけを2・4にする。掃引の計画の間だけ替え、runの記録の`joint_update_iterations_per_training_request`に、使った値が残ることを確かめた。事前学習と候補の学習は変えていない。
- agrawal4・randomrbf4・stagger3×間隔50×seed 0〜4×10 client×5000標本×回数2・4で、30 run・失敗0。掃引の壁時計は回数2が27分、回数4が48分。

- 出力: `results/fedhasp-training-iterations-v16/20261121_recurring-synthetic-interval50-seeds0-4`。集計は`analysis_training_iterations.md`と`analysis_assignment_destinations.md`（`tools/research_false_alarm_control_alpha`の集計）。

## まとめ（数値をそのまま述べる）
- 回数を増やすと、3データとも精度が上がった。上回ったseedは、全体で全セル4/5〜5/5。
  - agrawal4: 回数2で+4.45pp、回数4で+4.94pp。回数4の87.49は、FedDrift（87.48）と同じ。
  - randomrbf4: +1.27・+1.76pp。回数4の89.07は、FedDrift（89.34）まで−0.27pp。
  - stagger3: +0.29・+0.36pp。FedDrift（96.71）を上回ったまま。
- 安定した期間の精度も上がった（agrawal4で83.22→88.26、randomrbf4で87.94→89.76）。変化の直後の精度は、FedDriftより14〜38pp高いまま。
- 割り当ての誤りは少し減るだけで（agrawal4で24.35→20.08%）、違う概念どうしの統合は増える（agrawal4で2.0→6.6対）。それでもagrawal4では、回数2・4の精度（87.00・87.49）が、真の概念で割り当てる版（回数1、86.02）を上回る。
  - agrawal4で劣っていた主因は、割り当てより、保有モデルの学習の量だった。
  - [安定した期間の差の切り分け](stable-period-gap-recurring-synthetic-20261120.md)の、「割り当ての誤りが差の約半分を説明する」は、回数1での分解である。
- 費用:
  - client MACは約2倍・約4倍（agrawal4で0.020→0.041・0.086）。回数2で、FedDrift（0.021）の約2倍。
  - 経過時間は、1 runあたり約1.4〜1.9倍・約2.4〜3.2倍。
  - 下りの通信は+5〜+29%。上りはほぼ同じ。
- 解釈と限界:
  - この3データは、少ない標本からは学びにくい（[データの性質](stable-period-gap-recurring-synthetic-20261120.md#3-データの性質2026-11-20主担当の手元の短い測定)）。そのため、1標本1回の更新では学びが足りず、増やすと効いた。
  - FedDriftも、回数を増やせば上がる可能性がある。同じ計算量での比較はしていない。
  - 間隔500、元の10データ、seed 5〜9では確かめていない。
