# モデルの集まりで混ぜる効果と共有の効果を、最も単純な設定で理論と照らす（2026-11-24、主担当）

- 問い（外部からの指摘、2026-11-24ユーザー共有）: 「エキスパート統合をしないと性能が出ないのか。1モデルで予測する方式で同程度以上ができるのではないか。できるだけ単純なモデルで同じ条件で比べ、理論的に保証できる部分があると良い」。ユーザーの解釈（2026-11-24）: 指摘の「1モデル」は、モデルを複数持ち、予測は選んだ1つだけで行う方式（固い予測。FedDrift型）。
- ユーザーの見立て（2026-11-24）: 精度の理由は、(a) 別のclientが経験したモデルで、自分には未知の概念に対応できること、(b) 検出の遅れの期間や割り当ての誤りを、混ぜる予測が補えること。これを単純化して保証できないか。
- 既存の結果（神経網、10データ）との関係: 固い予測は柔らかい予測より−1.2〜−2.0pp、割り当てを真の概念にしても固い予測は−1.05pp（間隔50）。一方、FedDrift-Oracle（真の概念のモデル1つで固く予測、集約の時点で学習）は柔らかい予測を+0.47〜+1.07pp上回る（[ソフト予測とハード予測](hard-soft-prediction-v16-20261119.md)）。混ぜる効果は区間の種類で違い、全体で初めての区間で小さく、他のclientが経験済みの区間で大きい（[1クライアントの予備実験](fedhasp-single-client-pilot-v16.md)の「仮説1の切り分け」）。

## 1. 理論の見通し（証明の見通しであり、証明はしていない）

設定を次のように単純化する: 概念はK個、変化は急、損失は有界（二乗損失で予測とラベルを[−B, B]に収める）、各clientの系列の長さT、切り替えの回数S、予測に使えるモデルの数N。モデルの集まりの各モデルの予測は、時刻tのラベルを見る前に決まる（学習の途中のモデルでよい）。

- **補題A（混ぜる予測の保険。Herbster & Warmuth 1998のFixed Share）**: 損失がη-exp-concave（二乗損失なら η = 1/(8B²)）のとき、共有率α ≈ S/T の混合は、任意の「S回切り替える、使うモデルの列」に対して
  L_混合 ≤ L_列 + (S+1)(ln N + ln(eT/S)) / η
  を満たす。比べる列に「真の概念のモデルの列」を取れば、混合と真の概念のモデル（Oracleの固い予測）の差は、**切り替え1回あたり (ln N + ln(eT/S))/η 以下で、検出の遅れや割り当ての誤りに依らない**。遅れ・誤りが効くのは、モデルの学習（補題C）を通してだけ。
- **補題B（固い予測の費用）**: 固い予測と真の概念のモデルの差は、割り当てが真の概念と違う標本での損失の差の和。モデルが自分の概念でε程度に学習できていて、概念の違いがΔ（線形・等方の入力なら Δ = ||w_j − w_k||² = 2s²）なら、
  L_固い − L_真 ≈ Δ ×（遅れの標本数 S·d ＋ 誤って割り当てた標本数）。
  - A・Bから、**混合が固い予測を上回る条件は、切り替え1回あたり d·Δ（＋誤りの分）> (ln N + ln(eT/S))/η**。遅れも誤りも無ければ、固い予測（真の概念の1モデル）の方が良い。FedDrift-Oracleが柔らかい予測を上回った既存の結果と合う。
- **補題C（誤った学習による汚れ）**: 概念kのモデルが、学習の標本の割合ρだけ別の概念から学ぶと、最小二乗の解は真の係数から ρ×（概念の差）だけずれ、概念kでの余分な損失は ρ²Δ の程度（ρの2乗）。遅れが間隔に比べて短ければ（ρ ≈ d/I）、汚れの費用は予測の費用（補題B、ρの1乗）より小さい。
- **補題D（共有の効果）**: モデルIDごとに全clientで平均すると、概念kのモデルは全clientの標本 n_k = Σ_m n_{m,k} で学ぶ。あるclientが概念kに初めて出会ったとき、単独なら0から学び直す費用（オンライン勾配法の後悔の程度）を払うが、共有なら、他のclientが学んだ n_k 件分の誤差（最小二乗なら dσ²/n_k の程度）だけで済む。**利得は「自分には初めてで、他のclientが経験済み」の区間に集中する**。補題Aの比べる列は「そのclientが持つモデルの集まり」の中から選ぶので、共有で集まりに学習済みのモデルが入ると、遅れ・誤りがあっても混合はそのモデルへ早く重みを移せる。(a)と(b)は、この形でつながる。
- 合わせた形（clientmの累積損失の見通し）: L_混合,m ≤ Σ_t [σ² + 概念c_tのモデルの余分な損失（学習の量と汚れ）] + (S_m+1)(ln N + ln(eT/S_m))/η。共有の有無は第2項の学習の量に、遅れ・誤りは第2項の汚れ（ρ²）と、固い予測なら追加の Δ×（遅れ＋誤り）の項に入る。
- 保証の外にあるもの: 神経網（非凸）、検出器・MDLによる割り当てそのものの誤りの確率（窓の長さwと概念の違いΔによる。IFCAの補題に当たる見通しは (K−1)·exp(−wΔ²/(2σ²)) の形）、モデルIDの統合、事前学習。保証の η は理論値より小さく、実験では調整した値を使う（実験は保証の「形」を確かめる）。

## 2. 実験（制御した割り当て、研究ツール `tools/research_linear_concept_pool`）

- 設定: 線形回帰、入力10次元（標準正規）、概念K=4（真の係数は直交する方向に大きさs。概念の違い Δ = 2s²）、雑音σ=1（損失の下限1）、1 clientあたり3,000標本、区間の長さ（間隔）I、同期50標本ごと。学習は割り当てたモデルを標本1件ごとにSGDで1回（全方式で同じ学習の集まり）。学習の割り当ては真の概念で、変化から遅れd件は前の割り当てのまま、変化ごとに確率pで別の保有モデルへその区間の終わりまで誤る（実験の側で与える。検出器は無い）。予測は、固い予測（割り当てたモデル）、混合（保有モデルのFixed-Share）、真の概念のモデル（比べる相手）、単一モデル（全標本でSGD）。共有（10 clientでモデルIDごとに平均）・共有なし（10 client単独）・1 clientの3通り。
- 掃引: s∈{0.3, 1, 3}×I∈{50, 200, 1000}×d∈{0, 5, 20, 50}（d<I）×p∈{0, 0.2}×3通りの198 cell。学習率（5値）と混合の学習率・共有率（4×3値）を、調整用のseed 100〜104で方式ごとに選び、評価用のseed 0〜9で比べる。
- 実行: 手元のWindows、14 workers、2,970 run、壁時計297秒（1 runで全方式・全設定を同時に計算するので、方式ごとの時間は分けられない）。出力は`results/linear-concept-pool/20261124_controlled-assignment-v1/`（`runs.csv`・`run_record.json`・`analysis_linear_concept_pool.md`。Git管理外）。runの記録のcommitは`e8151c87`で、ツールは未commitの状態だった（直後にcommitした。下の台帳を参照）。

### 結果（数値は評価用seedの平均。差は対にした95%区間。分類ではないので精度は無く、損失で比べる）

- **遅れも誤りも無いとき、固い予測（＝真の概念のモデル）が混合より良い**（9 cellすべて、10/10 seed）。例: s=1・I=200で固い1.062、混合1.137。指摘の「選んだ1モデルで同程度以上」は、割り当てが正しく遅れが無い限り、この設定では正しい。
- **混合の費用は、切り替え1回あたりほぼ一定**（補題Aの形）: 1回あたりの費用Cの実測は、s=1でI=50・200・1000に対し11.9・16.0・20.3、s=3で39.1・45.5・52.9（間隔が20倍でも1.3〜1.7倍）。混合−真の概念のモデルは、遅れ・誤りを増やしても、遅れ0・誤り0の値をほとんど超えない（s=1・I=1000で0.013〜0.016対0.014。大きく汚れると、真の概念のモデル自身が汚れるので負にもなる）。
- **入れ替わりの位置は、補題A・Bの予測 d* = C/(2s²) と合う**（誤り0、混合−固い予測）:

| s | 予測 d*（I=50／200／1000） | 遅れ5 | 遅れ20 | 実際に混合が上回る最小の遅れ |
|---|---|---|---|---|
| 0.3 | 13／34／65 | 固いが良い | ほぼ同じ（I=50で+0.001） | 50まででは無い（I=200の遅れ50でほぼ同じ） |
| 1 | 5.9／8.0／10.2 | 固いが良い | 混合が良い | 20（3間隔とも） |
| 3 | 2.2／2.5／2.9 | 混合が良い | 混合が良い | 5（3間隔とも） |

  s=0.3では、予測より少し遅い（固い予測の遅れの実際の費用が2s²×遅れより小さいため。下を参照）。
- **固い予測の費用（補題B）は、向きと大きさの程度は合うが、2s²×（誤った学習の割合）は過大**: 汚れが小さいとき（I=1000・誤り0、s=1）、遅れ5・20・50で実測0.006・0.019・0.038、予測0.007・0.026・0.065。汚れが大きいほど過大になる（遅れの間に前のモデルが新しい概念も学び、モデルどうしの差が縮むため）。
- **誤った割り当て（p=0.2、遅れ0）**: s=1のI≥200とs=3の全間隔で混合が良い。s=1のI=50とs=0.3では固いが良い。
- **汚れ（補題C）**: 真の概念のモデルも、遅れ・誤りで悪くなる（s=1・I=200で遅れ50なら+0.128）。混合も固い予測もこれを払う。
- **変化からの経過**（s=1・I=200）: 遅れ0では、変化の直後0〜4標本で混合2.63対固い1.15（混合は重みを移すのに数標本かかる）。遅れ20では、固い予測は0〜19標本で2.4〜2.8のまま。混合は5〜9標本で1.62、10〜19標本で1.27へ戻る（**回復の速さが遅れに依らない**）。神経網の結果（変化から5〜49標本で柔らかい予測が6〜7pp上）と同じ形。
- **共有の効果（補題D）**: 遅れ0・誤り0では、共有の利得は「自分には初めてで他のclientが経験済み」の区間に集中する（s=1・I=50の固い予測で−0.357、ほかの種類は−0.05〜+0.02。s=3では−2.87、ほかは−0.09〜+0.14）。全体で初めての区間ではほぼ0。遅れ20・誤り0.2では、固い予測の共有の利得が縮み、全体で初めての区間では悪化する（s=1・I=200で+0.071、s=3・I=200で+0.539。誤った学習が共有で他のclientのモデルを汚す）。混合はこの条件でも他のclientが経験済みの区間の利得を保つ（s=1・I=200で混合−0.288、固い−0.045）。(a)と(b)がつながるという見通しと合う。
  - 説明できていない値が1つある。s=3・I=50・遅れ20・誤り0.2の混合は、最初の区間で共有あり−なし=+4.37。誤った学習の割合が48%と極端な条件で、方式ごとの設定の選択（全体の損失で選ぶ）が共有あり・なしで違うことが関わるとみるが、確かめていない。
- **単一モデル**: 198 cell中188で混合より悪い。例外の10 cellは、すべて共有なし（10 client単独か1 client）で遅れが20〜50。この単純な設定では、概念が対立するので、文脈を持たない単一の線形モデルは表せない（Aの意味の1モデル）。
- 標準指標（s=1・I=200・遅れ0・誤り0、1 clientあたり）: 上りは固い予測・混合が739、単一モデルが600浮動小数点数。下りは2,245と600。予測のMAC/標本は固い10、混合37（保有モデル全部を計算）、単一10。学習のMAC/標本はどれも20。経過時間は方式ごとに分けられない（1 run平均1.36秒）。

### まとめ（数値をそのまま述べる）と限定

- 最も単純な設定では、**混ぜる予測が本質なのではなく、割り当ての遅れと誤りがあるときの保険**である。遅れも誤りも無ければ、選んだ1モデル（固い予測）の方が良い。どちらが良いかは、切り替え1回あたりの混合の費用Cと、遅れ×概念の違い（d·2s²）の大小で決まり、入れ替わりの位置は d* = C/(2s²) の予測とs=1・3で合った。
- 共有の利得は、自分には初めてで他のclientが経験済みの区間に集中する。遅れ・誤りがあると、固い予測ではこの利得が縮み、混合では保たれる。
- 神経網のFedHASPとの対応で、説明できない部分が残る。神経網では、変化の無い時期（最初の変化の前、500標本以降）でも柔らかい予測が1.4〜2.6pp上で、その多くは同期と手元の2つの版の混合（+1.6pp）による。この単純な設定では、変化の無い時期に混ぜる利得は無い（線形モデルが真の係数へほぼ収束し、版も1つ）。指摘への答えでは、(a)・(b)に加えて、「版の混合による分散の低減（アンサンブルの効果）」を別の理由として分ける必要がある。この理論的な見通し（SGDの反復の平均で分散が下がる、など）は、ここでは扱っていない。
- 限定: 割り当ては実験の側で与えた（検出器・MDLの誤りの確率そのものは扱っていない）。Cは実測で、Fixed-Shareの保証の理論値（η = 1/(8B²)）より小さい学習率の保証を数値で確かめたわけではない（形だけを確かめた）。損失は回帰の二乗誤差で、分類の精度ではない。
