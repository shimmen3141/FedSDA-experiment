## A.1 設定

client c ∈ {1, …, C} は時刻 t = 1, …, T に、入力 x と実数のラベル y を受け取る（理論は回帰の二乗損失で述べる。分類の精度への翻訳はしていない）。clientが時刻tに従う概念を z_t、概念zの真の係数を θ*_z、概念の違いを Δ := min_{z≠z'} ‖θ*_z − θ*_{z'}‖² とする。概念の列はあらかじめ決まっている（学習者の振る舞いに依らない）とし、clientあたりの切り替えの回数を S とする。

各clientはモデルの集まりを持ち、時刻tにモデルkは係数 θ_{k,t} を持つ。θ_{k,t} は時刻tのラベルを見る前の情報だけで決まる（学習の途中でよい）。モデルkが表す概念 κ(k) は、学習の標本の多数派の概念とする。予測の方式は3つ:
- 固い予測: 割り当てたモデル a_t の予測 f_{a_t,t}(x_t)。割り当ての列の切り替えの回数を S^a とする（同じ概念の重複したモデルの間の行き来も数える）。
- 真の概念のモデル（比べる相手。実際には使えない）: 各概念zに代表のモデル r(z) を1つ固定し（同じ概念の重複があっても代表は1つ）、k*_t := r(z_t) として f_{k*_t,t}(x_t)。この列の切り替えの回数は S。
- 混合: 下のFixed Share。

仮定（結果ごとにどれを使うかを書く）:
- (B) 有界性: 全ての予測とラベルが [−B, B] に入る（例: 入力が有界、係数を半径Θの球へ射影、雑音が有界）。
- (L) 線形・等方: E[x] = 0、E[xxᵀ] = I。ラベルは y = ⟨θ*_{z_t}, x⟩ + ξ で、ξ は入力と独立に平均0・分散σ²。このとき E[(⟨θ, x⟩ − y)²] = σ² + ‖θ − θ*_z‖²。
- (G) 正規: (L) に加えて、x ~ N(0, I_d)、ξ ~ N(0, σ²)。
- (E) ε-精度: 考える時刻で、全てのモデルが ‖θ_{k,t} − θ*_{κ(k)}‖² ≤ ε を満たす。
- (O) 代表の存在: 考える時刻で、各概念 z_t の代表のモデル r(z_t) が作られていて、κ(r(z)) = z。（全体で初めての概念の直後など、代表がまだ無い期間は(O)が成り立たない。そこでは真の概念のモデルとの比較は定義せず、定理1を、実際に比べる列の切り替えの回数 S_orc で使う。）

## A.2 定理1（混合は、どの「モデルを選ぶ列」にも対数の費用で追いつく）【適用】

**アルゴリズム**: モデルの数の上限を N とし、N個のエキスパートを最初から置く。まだ作られていないモデルに当たるエキスパートは、その時刻の「作られたモデルだけの重み付き平均」を予測する。統合では、統合先iの予測は統合後の係数による予測に変わり、統合元jはその後iと同じ予測をする。混合は全エキスパートの重み付き平均を予測し、損失で重みに exp(−η·損失) を掛け、原典の Fixed-share（各エキスパートが自分以外の N−1 個へ α/(N−1) ずつ配る）を行う。

**主張**: 仮定(B)、η = 1/(8B²)、0 < α < 1 のとき、任意の系列と、各時刻にエキスパートを1つ選ぶ任意の列 e（切り替え S_e 回）について

L^mix ≤ L^e + R_α(S_e)、　R_α(s) := (1/η)[ln N + s(ln(N−1) + ln(1/α)) + (T−1−s) ln(1/(1−α))]。

特に、仮定(O)が全時刻で成り立つとき、同じアルゴリズムで同時に L^mix ≤ min{ L^hard + R_α(S^a), L^orc + R_α(S) }（(O)が一部の期間で成り立たないなら、その期間に使う列を含めた実際の切り替えの回数 S_orc で R_α(S_orc)）。α = S/(T−1)（1 ≤ S ≤ T−2。αが(0,1)に入る範囲）とすると R_α(S) ≤ (1/η)[ln N + S ln(N−1) + S ln((T−1)/S) + S]。切り替えの無い列（S_e = 0）と比べるときは、R_α(0) = (1/η)[ln N + (T−1) ln(1/(1−α))]。

**証明**: Herbster & Warmuth (1998) の Theorem 1 は、結果とエキスパートの予測が [0, 1] で、損失と予測関数が (c, η)-realizable（η = 1/c）のとき、任意の系列と任意の分割について上の形の上界を与える（エキスパートの予測と結果の関係に仮定を置かないので、過去に依存して学習するモデルの予測でよい）。二乗損失と重み付き平均の予測は (2, 1/2)-realizable（原典 Figure 2）で、[−B, B] を [0, 1] へ線形に写すと損失が 4B² 倍になるので η = 1/(8B²)。まだ作られていないエキスパートの予測を、作られたものの重み付き平均 q とすると、全体の重み付き平均は (Σ_作られた w f + W_未 q)/(W_作 + W_未) = q となり、自己無撞着で、ラベルを見る前に決まり、[−B, B] に入る。統合の後のjの予測もラベルの前に決まる。よって原典の上界がそのまま当てはまる。α = S/(T−1) のときの値は原典の Corollary 1（(T−1−S) ln(1 + S/(T−1−S)) ≤ S を使う）。∎

**注**: (1) 実装（実験の研究ツール・製品）とは次が違うので、定理は実装をそのまま保証しない: 作られていないモデルを重みの計算から外し、作られた時点で重み α'/保有数 で入れる。統合でjの重みをiへ足してjを消す。予測を [−B, B] に切り詰めない。混合の学習率を調整して η = 1/(8B²) より大きくする。共有の式 v ← (1−α')v + α'/N は、Nが一定の間は原典の式と α = α'(N−1)/N で同じ。(2) 理論値の η では上界は実測より桁で大きく、実験で確かめたのは形だけ（A.8）。

## A.3 命題2（固い予測の費用）と系3（混合が固い予測を上回る条件）【適用】

**命題2**: 仮定(L)、(E)、(O)のもとで（数える時刻の全てで成り立つとき）、n^wrong := #{t : κ(a_t) ≠ z_t}（別の概念のモデルへ割り当てた標本の数）、n^dup := #{t : κ(a_t) = z_t, a_t ≠ k*_t}（同じ概念の別のモデル＝重複へ割り当てた標本の数）とすると、
E[L^hard] − E[L^orc] ≥ (Δ − 2√(Δε))·E[n^wrong] − ε·E[n^dup]。

**証明**: (L)から、過去を条件とした1標本の期待損失は σ² + ‖θ − θ*_{z_t}‖²。κ(a_t) ≠ z_t の時刻では、三角不等式と(E)より ‖θ_{a_t} − θ*_{z_t}‖ ≥ √Δ − √ε（ε < Δ のとき）、また ‖θ_{k*_t} − θ*_{z_t}‖² ≤ ε なので、差は (√Δ − √ε)² − ε = Δ − 2√(Δε) 以上。重複の時刻は、固い予測の期待損失が σ² 以上、真の概念のモデルが σ² + ε 以下なので、差は −ε 以上。a_t = k*_t の時刻は差が0。条件付き期待値を足す。∎

**系3**: 仮定(B)(L)(E)(O)が全時刻で成り立ち、ε < Δ/4 のもとで、(Δ − 2√(Δε))·E[n^wrong] − ε·E[n^dup] > R_α(S) なら E[L^mix] < E[L^hard]（n^dup は同じ概念の別のモデルへ割り当てた標本の数）。切り替えのたびに、その後のd件が別の概念のモデルへ割り当てられるなら n^wrong ≥ S·d で、α = S/(T−1) のとき、おおよそ d > (ln(N−1) + ln(e(T−1)/S))/(η(Δ − 2√(Δε))) を超える遅れで混合が上回る。遅れも誤りも無ければ（n^wrong = 0）、固い予測は真の概念のモデルと一致し、混合は最大 R_α(S) だけ悪くなりうる。

**証明**: 定理1は各系列で成り立つので期待値を取れる。命題2と合わせる。∎

**注**: (B)と(L)を同時に満たすには、有界で E[xxᵀ] = I の入力（例: 各成分が ±1）と有界な雑音を考える。(E)は学び始めのモデルや汚れたモデルでは成り立たないので、系3はモデルが学習できた後の期間についての主張である。

## A.4 補題4（誤った学習による汚れ）【適用】

**主張**: 仮定(L)の概念の混合で、モデルが概念zの標本と、割合 ρ_j で概念jの標本から学ぶとき（Σ_j ρ_j = ρ）、母集団の最小二乗解は θ̄ = (1−ρ)θ*_z + Σ_j ρ_j θ*_j、概念zでの余分な損失は ‖Σ_j ρ_j(θ*_j − θ*_z)‖²。1つの概念jだけなら ρ²‖θ*_j − θ*_z‖²。

**証明**: 各概念で E[xxᵀ] = I、E[xy] = θ*_z なので、混合の正規方程式の解は重み付き平均。概念zでの損失は σ² + ‖θ̄ − θ*_z‖²。∎

**注**: 標本が無限の母集団の解についての主張で、有限標本・SGDの保証ではない。共有では、モデルIDごとに全clientの標本で学ぶので、ρは全clientの誤った学習の割合になる。

## A.5 命題5（窓の検定で選び間違える確率と、まとまる条件）【適用】

**仮定**: (G)。窓のw件は1つの概念zから独立に来て、窓の間モデルを固定とみなす。モデルkの残差の分散を v_k := σ² + ‖θ_k − θ*_z‖² とする（残差は N(0, v_k)、窓の平均損失 L̄_k は v_k·χ²_w/w）。

**主張**: (a) v_k < v_j、g := v_j − v_k のとき、P(L̄_j ≤ L̄_k) ≤ 2 exp(−w g²/(25 v_j²))。保有するN個のモデルについて和を取ると、正しいモデル以外を選ぶ確率は 2(N−1) exp(−w g_min²/(25 v_max²)) 以下。(b) 概念zのモデルがまだ無く、今のモデルjが別の概念のとき、新しいモデルを作る閾値τに対して v_j(1 + 2√(u/w) + 2u/w) ≤ τ なら、確率 1 − e^{−u} 以上で L̄_j ≤ τ となり、新しいモデルは作られない（zはjにまとまる）。

**証明**: Laurent & Massart (2000) の Lemma 1 の系 (4.3) P(U − w ≥ 2√(wu) + 2u) ≤ e^{−u}、(4.4) P(w − U ≥ 2√(wu)) ≤ e^{−u}（Uは自由度wのχ²）を使う。ρ := √(u/w) とする。(a) ρ = g/(5v_j) と置くと ρ ≤ 1/5 なので 2ρ² ≤ ρ、また 3v_k + 2v_j ≤ 5v_j より v_k(1 + 3ρ) ≤ v_j(1 − 2ρ)。L̄_k ≥ v_k(1 + 2ρ + 2ρ²) と L̄_j ≤ v_j(1 − 2ρ) のどちらも起きなければ L̄_k < L̄_j。2つの事象の確率は e^{−u} 以下で、u = w g²/(25 v_j²)。(b) は (4.3) をそのまま使う。∎

**注**: (b)は十分条件。v_j ≈ σ² + Δ、τ = σ²(1 + z√(2/w)) を入れ、Δ ≪ σ² で u/w の項を無視すると、おおよそ w ≲ 2z²σ⁴/Δ² のときまとまる形になる（必要条件ではない）。

## A.6 命題6（モデルの共有の利得）【既知＋適用】

**主張**: 仮定(G)で、概念zの標本 n 件（n ≥ d + 2）から切片なしの最小二乗で学んだモデルの、次の独立な標本での期待の超過損失は σ²d/(n − d − 1)（n ≤ d + 1 では無限大）。共有で、他のclientがすでに正しく割り当てた n_z 件を学んでいれば、自分の n 件目の後の期待の超過損失は σ²d/(n_z + n − d − 1) で、共有なしの σ²d/(n − d − 1) より小さい。全体で初めての概念（n_z = 0）では差が無い。

**証明**: Breiman & Freedman (1983) の Theorem 1.1（全ての変数を使う場合）。Belkin, Hsu & Xu の Theorem 1 にも同じ式がある。導出は、Xを条件とした推定の誤差の共分散 σ²(XᵀX)⁻¹ と、逆Wishartの平均 E[(XᵀX)⁻¹] = I/(n − d − 1) による。∎

**注**: 同期の遅れと汚れ（補題4）は無いとした。定理1の比べる列は「そのclientが持つモデルの集まり」から選ぶので、共有で学習済みのモデルが集まりに入れば、割り当てが遅れていても、混合はそのモデルの損失に R_α の費用で追いつく。固い予測は、正しいモデルへ割り当てるまで共有の利得を受け取れない（命題2の n^wrong の期間）。

## A.7 命題7（同期の版と手元の版の混合）【適用＋予想】

**主張（適用）**: 2つの版（同期の時点のモデルと、手元で更新したモデル）を2つのエキスパートとする Fixed Share は、定理1（N = 2）により、どちらの版をいつ使うかの任意の切り替えの列に R_α の費用で追いつく。さらに二乗損失では恒等式 ℓ(Σ v_i f_i) = Σ v_i ℓ(f_i) − Σ v_i (f_i − p)²（p = Σ v_i f_i）が成り立ち、混ぜた予測は2つの損失の重み付き平均より、2つの食い違いの分だけ良い。

**予想（概略）**: 線形・定常・clientのSGDの雑音が互いに独立なとき、全clientで平均した同期の版の誤差の分散は、1 clientの分散のおよそ 1/C。手元の版は同期からの件数だけ自分の雑音を足す。したがって、同期が頻繁で変化が無い期間は同期の版が良く、変化の直後は（同期の版が最大Iだけ古いので）手元の版が良い。混合はその良い方に追いつく。
