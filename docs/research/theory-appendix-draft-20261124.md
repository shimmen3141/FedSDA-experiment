## A.1 設定

client c ∈ {1, …, C} は時刻 t = 1, …, T に、入力 x と実数のラベル y を受け取る（理論は回帰の二乗損失で述べる。分類の精度への翻訳はしていない）。clientが時刻tに従う概念を z_t、概念zの真の係数を θ*_z、概念の違いを Δ := min_{z≠z'} ‖θ*_z − θ*_{z'}‖² とする。概念の列はあらかじめ決まっている（学習者の振る舞いに依らない）とし、clientあたりの切り替えの回数を S とする。

各clientはモデルの集まりを持ち、時刻tにモデルkは係数 θ_{k,t} を持つ。θ_{k,t} は時刻tのラベルを見る前の情報だけで決まる（学習の途中でよい）。モデルkが表す概念 κ(k) は、学習の標本の多数派の概念とする。予測の方式は3つ:
- 固い予測: 割り当てたモデル a_t の予測 f_{a_t,t}(x_t)。割り当ての列の切り替えの回数を S^a とする（同じ概念の重複したモデルの間の行き来も数える）。
- 真の概念のモデル（比べる相手。実際には使えない）: 各概念zに代表のモデル r(z) を1つ固定し（同じ概念の重複があっても代表は1つ）、k*_t := r(z_t) として f_{k*_t,t}(x_t)。この列の切り替えの回数は S。
- 混合: 下のFixed Share。

仮定（結果ごとにどれを使うかを書く）:
- (B) 有界性: 全ての予測とラベルが [−B, B] に入る（例: 入力が有界、係数を半径Θの球へ射影、雑音が有界）。
- (L) 線形・等方: E[x] = 0、E[xxᵀ] = I。ラベルは y = ⟨θ*_{z_t}, x⟩ + ξ で、ξ は入力と独立に平均0・分散σ²。このとき E[(⟨θ, x⟩ − y)²] = σ² + ‖θ − θ*_z‖²。
- (G) 正規: (L) に加えて、x ~ N(0, I_d)、ξ ~ N(0, σ²)。
- (E) ε-精度: 考える時刻で、全てのモデルが ‖θ_{k,t} − θ*_{κ(k)}‖² ≤ ε を満たす。
- (O) 代表の存在: 考える時刻で、各概念 z_t の代表のモデル r(z_t) が作られていて、κ(r(z)) = z。（全体で初めての概念の直後など、代表がまだ無い期間は(O)が成り立たない。そこでは真の概念のモデルとの比較は定義せず、定理1を、実際に比べる列の切り替えの回数 S_orc で使う。）

## A.2 定理1（混合は、どの「モデルを選ぶ列」にも対数の費用で追いつく）【適用】

**アルゴリズム**: モデルの数の上限を N とし、N個のエキスパートを最初から置く。まだ作られていないモデルに当たるエキスパートは、その時刻の「作られたモデルだけの重み付き平均」を予測する。統合では、統合先iの予測は統合後の係数による予測に変わり、統合元jはその後iと同じ予測をする。混合は全エキスパートの重み付き平均を予測し、損失で重みに exp(−η·損失) を掛け、原典の Fixed-share（各エキスパートが自分以外の N−1 個へ α/(N−1) ずつ配る）を行う。

**主張**: 仮定(B)、η = 1/(8B²)、0 < α < 1 のとき、任意の系列と、各時刻にエキスパートを1つ選ぶ任意の列 e（切り替え S_e 回）について

L^mix ≤ L^e + R_α(S_e)、　R_α(s) := (1/η)[ln N + s(ln(N−1) + ln(1/α)) + (T−1−s) ln(1/(1−α))]。

特に、仮定(O)が全時刻で成り立つとき、同じアルゴリズムで同時に L^mix ≤ min{ L^hard + R_α(S^a), L^orc + R_α(S) }（(O)が一部の期間で成り立たないなら、その期間に使う列を含めた実際の切り替えの回数 S_orc で R_α(S_orc)）。α = S/(T−1)（1 ≤ S ≤ T−2。αが(0,1)に入る範囲）とすると R_α(S) ≤ (1/η)[ln N + S ln(N−1) + S ln((T−1)/S) + S]。切り替えの無い列（S_e = 0）と比べるときは、R_α(0) = (1/η)[ln N + (T−1) ln(1/(1−α))]。

**証明**: Herbster & Warmuth (1998) の Theorem 1 は、結果とエキスパートの予測が [0, 1] で、損失と予測関数が (c, η)-realizable（η = 1/c）のとき、任意の系列と任意の分割について上の形の上界を与える（エキスパートの予測と結果の関係に仮定を置かないので、過去に依存して学習するモデルの予測でよい）。二乗損失と重み付き平均の予測は (2, 1/2)-realizable（原典 Figure 2）で、[−B, B] を [0, 1] へ線形に写すと損失が 4B² 倍になるので η = 1/(8B²)。まだ作られていないエキスパートの予測を、作られたものの重み付き平均 q とすると、全体の重み付き平均は (Σ_作られた w f + W_未 q)/(W_作 + W_未) = q となり、自己無撞着で、ラベルを見る前に決まり、[−B, B] に入る。統合の後のjの予測もラベルの前に決まる。よって原典の上界がそのまま当てはまる。α = S/(T−1) のときの値は原典の Corollary 1（(T−1−S) ln(1 + S/(T−1−S)) ≤ S を使う）。∎

**注**: (1) 実装（実験の研究ツール・製品）とは次が違うので、定理は実装をそのまま保証しない: 作られていないモデルを重みの計算から外し、作られた時点で重み α'/保有数 で入れる。統合でjの重みをiへ足してjを消す。予測を [−B, B] に切り詰めない。混合の学習率を調整して η = 1/(8B²) より大きくする。共有の式 v ← (1−α')v + α'/N は、Nが一定の間は原典の式と α = α'(N−1)/N で同じ。(2) 理論値の η では上界は実測より桁で大きく、実験で確かめたのは形だけ（A.8）。

## A.3 命題2（固い予測の費用）と系3（混合が固い予測を上回る条件）【適用】

**命題2**: 仮定(L)、(E)、(O)のもとで（数える時刻の全てで成り立つとき）、n^wrong := #{t : κ(a_t) ≠ z_t}（別の概念のモデルへ割り当てた標本の数）、n^dup := #{t : κ(a_t) = z_t, a_t ≠ k*_t}（同じ概念の別のモデル＝重複へ割り当てた標本の数）とすると、
E[L^hard] − E[L^orc] ≥ (Δ − 2√(Δε))·E[n^wrong] − ε·E[n^dup]。

**証明**: (L)から、過去を条件とした1標本の期待損失は σ² + ‖θ − θ*_{z_t}‖²。κ(a_t) ≠ z_t の時刻では、三角不等式と(E)より ‖θ_{a_t} − θ*_{z_t}‖ ≥ √Δ − √ε（ε < Δ のとき）、また ‖θ_{k*_t} − θ*_{z_t}‖² ≤ ε なので、差は (√Δ − √ε)² − ε = Δ − 2√(Δε) 以上。重複の時刻は、固い予測の期待損失が σ² 以上、真の概念のモデルが σ² + ε 以下なので、差は −ε 以上。a_t = k*_t の時刻は差が0。条件付き期待値を足す。∎

**系3**: 仮定(B)(L)(E)(O)が全時刻で成り立ち、ε < Δ/4 のもとで、(Δ − 2√(Δε))·E[n^wrong] − ε·E[n^dup] > R_α(S) なら E[L^mix] < E[L^hard]（n^dup は同じ概念の別のモデルへ割り当てた標本の数）。切り替えのたびに、その後のd件が別の概念のモデルへ割り当てられるなら n^wrong ≥ S·d で、α = S/(T−1) のとき、おおよそ d > (ln(N−1) + ln(e(T−1)/S))/(η(Δ − 2√(Δε))) を超える遅れで混合が上回る。遅れも誤りも無ければ（n^wrong = 0）、固い予測は真の概念のモデルと一致し、混合は最大 R_α(S) だけ悪くなりうる。

**証明**: 定理1は各系列で成り立つので期待値を取れる。命題2と合わせる。∎

**注**: (B)と(L)を同時に満たすには、有界で E[xxᵀ] = I の入力（例: 各成分が ±1）と有界な雑音を考える。(E)は学び始めのモデルや汚れたモデルでは成り立たないので、系3はモデルが学習できた後の期間についての主張である。

## A.4 補題4（誤った学習による汚れ）【適用】

**主張**: 仮定(L)の概念の混合で、モデルが概念zの標本と、割合 ρ_j で概念jの標本から学ぶとき（Σ_j ρ_j = ρ）、母集団の最小二乗解は θ̄ = (1−ρ)θ*_z + Σ_j ρ_j θ*_j、概念zでの余分な損失は ‖Σ_j ρ_j(θ*_j − θ*_z)‖²。1つの概念jだけなら ρ²‖θ*_j − θ*_z‖²。

**証明**: 各概念で E[xxᵀ] = I、E[xy] = θ*_z なので、混合の正規方程式の解は重み付き平均。概念zでの損失は σ² + ‖θ̄ − θ*_z‖²。∎

**注**: 標本が無限の母集団の解についての主張で、有限標本・SGDの保証ではない。共有では、モデルIDごとに全clientの標本で学ぶので、ρは全clientの誤った学習の割合になる。

## A.5 命題5（窓の検定で選び間違える確率と、まとまる条件）【適用】

**仮定**: (G)。窓のw件は1つの概念zから独立に来て、窓の間モデルを固定とみなす。モデルkの残差の分散を v_k := σ² + ‖θ_k − θ*_z‖² とする（残差は N(0, v_k)、窓の平均損失 L̄_k は v_k·χ²_w/w）。

**主張**: (a) v_k < v_j、g := v_j − v_k のとき、P(L̄_j ≤ L̄_k) ≤ 2 exp(−w g²/(25 v_j²))。保有するN個のモデルについて和を取ると、正しいモデル以外を選ぶ確率は 2(N−1) exp(−w g_min²/(25 v_max²)) 以下。(b) 概念zのモデルがまだ無く、今のモデルjが別の概念のとき、新しいモデルを作る閾値τに対して v_j(1 + 2√(u/w) + 2u/w) ≤ τ なら、確率 1 − e^{−u} 以上で L̄_j ≤ τ となり、新しいモデルは作られない（zはjにまとまる）。

**証明**: Laurent & Massart (2000) の Lemma 1 の系 (4.3) P(U − w ≥ 2√(wu) + 2u) ≤ e^{−u}、(4.4) P(w − U ≥ 2√(wu)) ≤ e^{−u}（Uは自由度wのχ²）を使う。ρ := √(u/w) とする。(a) ρ = g/(5v_j) と置くと ρ ≤ 1/5 なので 2ρ² ≤ ρ、また 3v_k + 2v_j ≤ 5v_j より v_k(1 + 3ρ) ≤ v_j(1 − 2ρ)。L̄_k ≥ v_k(1 + 2ρ + 2ρ²) と L̄_j ≤ v_j(1 − 2ρ) のどちらも起きなければ L̄_k < L̄_j。2つの事象の確率は e^{−u} 以下で、u = w g²/(25 v_j²)。(b) は (4.3) をそのまま使う。∎

**注**: (b)は十分条件。v_j ≈ σ² + Δ、τ = σ²(1 + z√(2/w)) を入れ、Δ ≪ σ² で u/w の項を無視すると、おおよそ w ≲ 2z²σ⁴/Δ² のときまとまる形になる（必要条件ではない）。

## A.6 命題6（モデルの共有の利得）【既知＋適用】

**主張**: 仮定(G)で、概念zの標本 n 件（n ≥ d + 2）から切片なしの最小二乗で学んだモデルの、次の独立な標本での期待の超過損失は σ²d/(n − d − 1)（n ≤ d + 1 では無限大）。共有で、他のclientがすでに正しく割り当てた n_z 件を学んでいれば、自分の n 件目の後の期待の超過損失は σ²d/(n_z + n − d − 1) で、共有なしの σ²d/(n − d − 1) より小さい。全体で初めての概念（n_z = 0）では差が無い。

**証明**: Breiman & Freedman (1983) の Theorem 1.1（全ての変数を使う場合）。Belkin, Hsu & Xu の Theorem 1 にも同じ式がある。導出は、Xを条件とした推定の誤差の共分散 σ²(XᵀX)⁻¹ と、逆Wishartの平均 E[(XᵀX)⁻¹] = I/(n − d − 1) による。∎

**注**: 同期の遅れと汚れ（補題4）は無いとした。定理1の比べる列は「そのclientが持つモデルの集まり」から選ぶので、共有で学習済みのモデルが集まりに入れば、割り当てが遅れていても、混合はそのモデルの損失に R_α の費用で追いつく。固い予測は、正しいモデルへ割り当てるまで共有の利得を受け取れない（命題2の n^wrong の期間）。

## A.7 命題7（同期の版と手元の版の混合）【適用＋予想】

**主張（適用）**: 2つの版（同期の時点のモデルと、手元で更新したモデル）を2つのエキスパートとする Fixed Share は、定理1（N = 2）により、どちらの版をいつ使うかの任意の切り替えの列に R_α の費用で追いつく。さらに二乗損失では恒等式 ℓ(Σ v_i f_i) = Σ v_i ℓ(f_i) − Σ v_i (f_i − p)²（p = Σ v_i f_i）が成り立ち、混ぜた予測は2つの損失の重み付き平均より、2つの食い違いの分だけ良い。

**予想（概略）**: 線形・定常・clientのSGDの雑音が互いに独立なとき、全clientで平均した同期の版の誤差の分散は、1 clientの分散のおよそ 1/C。手元の版は同期からの件数だけ自分の雑音を足す。したがって、同期が頻繁で変化が無い期間は同期の版が良く、変化の直後は（同期の版が最大Iだけ古いので）手元の版が良い。混合はその良い方に追いつく。

## A.7b 定理8（自分は未経験だが他のclientが学んだ概念での利得と、柔らかい重みの役割）（2026-11-24追記）

ユーザーの指摘（2026-11-24）: 連合学習では、普通のオンライン学習やエキスパート統合と違い、「自分はまだ経験していないが正解のモデル」を持てる。モデルを共有する他の方式（FedDriftなど）も持てるが、FedHASPはそれを柔らかい重みで、割り当てが決まる前から使う点が違う。定理8はこれを (a) 共有の上界、(b) 単独の学習者の下界、(c) 固い割り当ての費用 の3つに分けて述べる。

**設定**: clientのある区間 [t₀, t₀ + n₀) が、そのclientには初めての概念zに従う。他のclientがzを学び、時刻 t₀ より前の同期で、その代表のモデル r(z)（他のclientの正しく割り当てた n_z 件で学んだもの）がこのclientに届いている（仮定(O)がこの区間で成り立つ）。

**(a) 共有の上界【概略。証明は A.7c】**: 定理1は系列全体の上界なので、区間だけを切り出さず、比べる列の変更として述べる。任意の比べる列 e'（各時刻に作られたエキスパートを1つ選ぶ列、切り替え S_{e'} 回）から、区間の外では e' と同じエキスパートを、区間の中では r(z) を選ぶ列 e を作る（(O)より r(z) は区間の間作られている）。e の切り替えの回数は S_e ≤ min(S_{e'} + 2, T − 1)（区間の始まりと終わりで最大2回増え、長さTの列なので T − 1 回を超えない）。定理1を e に当てはめると L^mix ≤ L^e + R_α(S_e)。α ≤ (N−1)/N のとき R_α(s+1) − R_α(s) = (1/η) ln((N−1)(1−α)/α) ≥ 0 で、S_e − S_{e'} ≤ 2 なので、R_α(S_e) ≤ R_α(S_{e'}) + (2/η) ln((N−1)(1−α)/α) ≤ R_α(S_{e'}) + (2/η)[ln(N−1) + ln(1/α)]。つまり、区間の外は e' と同じ損失のまま、区間の中で r(z) の損失に追いつくための追加の費用は、切り替え2回分（「N個の候補から正しいモデルを探す費用」）で抑えられる。最初の費用 (1/η) ln N と、毎時刻の共有の費用 (T−1−s)(1/η) ln(1/(1−α)) は、e' と e のどちらを比べても同じだけかかる系列全体の費用で、この区間に固有のものではない。区間の中の L^e は r(z) 自身の損失で、r(z) が他のclientの n_z 件（n_z ≥ d + 2）から学んだ最小二乗で区間の間変わらないとき、仮定(G)のもとで超過分の期待値は n₀σ²d/(n_z − d − 1)（命題6）で、n_z が大きいほど0に近い（A.7cで証明する範囲。区間の中で r(z) が学び続ける場合は証明していない）。

**(b) 単独の学習者の下界【証明】**: 仮定(G)に加えて、概念zの係数 θ*_z が事前分布 N(0, τ²I_d) から、他の全ての概念の係数・入力・雑音と独立に選ばれるとする。このclientが自分の過去の標本だけから予測を作る任意の方式（予測は今の入力と自分の過去の標本の関数）は、区間の最初の n₀ 件で
E[Σ_{i=0}^{n₀−1} ((ŷ_i − y_i)² − σ²)] ≥ dσ² ln(1 + n₀τ²/σ²)
を払う（期待値は事前分布・入力・雑音と、方式が乱数を使うならその乱数について）。したがって、どの方式についても、入力・雑音（と方式の乱数）についての期待値でこの値以上を払う θ*_z が存在する（最悪の場合の下界。個々の雑音の系列での損失を保証するものではない）。区間の始まりは θ*_z と独立に決まるとする。

**証明**: 区間のi件目の予測の時点で、θ*_z について情報を持つのは、この区間の最初のi件だけ（他の標本は θ*_z と独立）。正規の事前分布と正規の雑音から、θ*_z の事後分布は正規で、共分散は Σ_i = (I/τ² + X_iᵀX_i/σ²)⁻¹（X_i はこの区間の最初のi件の入力）。新しい入力 x は過去と独立で、⟨θ*_z, x⟩ の、過去と x を与えたときの最良の予測（2乗誤差で）は事後平均で、その誤差の期待値は E[xᵀΣ_i x] = E[tr Σ_i]（E[xxᵀ] = I）。どの予測もこれ以上の誤差を持ち、雑音は独立なので、1件の期待の超過損失は E[tr Σ_i] 以上。行列の逆のトレースは正定値行列について凸なので、Jensenの不等式で E[tr Σ_i] ≥ tr((I/τ² + E[X_iᵀX_i]/σ²)⁻¹) = d/(1/τ² + i/σ²) = dσ²τ²/(σ² + iτ²)。a := σ²/τ² とおき、Σ_{i=0}^{n₀−1} 1/(a + i) ≥ ∫₀^{n₀} dx/(a + x) = ln(1 + n₀/a) を使う。∎

**(b)の数値の確認**（主担当、d = 10、σ = 1、各400回）: ベイズ最適（事後平均。自分のデータだけの方式の中で最良）の累積の超過損失は、τ ∈ {0.3, 1, 3}・n₀ ∈ {20, 100, 500} の9条件すべてで下界以上だった（例: τ = 0.3・n₀ = 100で 27.68 ± 0.86 対 下界 23.03。τ = 3・n₀ = 100で 556.06 ± 28.64 対 68.04）。τが大きいと下界は緩い（Jensenの不等式が学び始めの数件で緩いため）。

**(c) 固い割り当ての費用【適用】**: 仮定(L)(E)(O)のもとで、この区間で、割り当てが r(z)（またはzを表す重複）に移るまでに d₀ 件かかる固い予測は、命題2により、この区間だけで (Δ − 2√(Δε))·E[d₀] − （重複の項）以上を、真の概念のモデルより多く払う。共有のモデルがあっても、正しく割り当てるまではその利得を受け取れない。割り当てを集約の時点でだけ変える方式（FedDrift型）では、d₀ は、区間の始まりから次の集約までの件数以上になる（区間の始まりの位置による。最大で約 I。区間の始まりが集約の周期の中で一様に分布すると仮定したときの平均は約 I/2 で、これは平均の値で、個々の区間の下界ではない）。

**意味**:
- (a)と(b)の比: 連合学習でモデルを共有する方式は、他のclientが十分に学んでいれば（n_z が大きい）、未経験の概念で「探す費用」（log N の程度）しか払わない。自分のデータだけの方式は、どのようなアルゴリズムでも「学ぶ費用」（dσ² log(n₀τ²/σ²) の程度）を、未経験の概念ごとに払う。これは、普通のオンライン学習・エキスパート統合（エキスパートは外から与えられるか、自分のデータで学ぶ）には無い、連合学習でモデルの集まりを共有することの利点で、FedDrift型の方式も持つ。
- (a)と(c)の比: 共有のモデルを使い始めるまでの遅れの費用は、固い割り当てでは概念の違いΔに比例して遅れの件数だけかかり、柔らかい重み（混合）では切り替えの費用（log の程度）で済む。FedHASPに固有なのはこの部分で、「自分は未経験の正解のモデル」を、割り当てが決まる前から重みに応じて使う。
- 実験との対応: 線形回帰の設定で、共有の利得は「自分には初めてで他のclientが経験済み」の区間に集中し、遅れ・誤りがあると固い予測ではその利得が縮み、混合では保たれた（[実験の記録](linear-concept-pool-theory-20261124.md)の2・3章）。神経網でも、混合の効果は他のclientが経験済みの区間で大きかった（[1クライアントの予備実験](fedhasp-single-client-pilot-v16.md)の仮説1の切り分け）。

**限定**: (a)は定理1（仮定(B)）と命題6（仮定(G)）を組み合わせた概略で、2つの仮定は同時には成り立たない（正規の入力は有界でない）。厳密にするには、切り詰めた予測での命題6の評価が要る（未着手）。(b)は事前分布の平均の下界で、事前分布の選び方（τ）に依る。実験の概念の係数（直交する方向に大きさs）は正規の事前分布から選んだものではない。(c)のFedDrift型の遅れは、集約の時点でだけ割り当てを変えるという単純化で、FedDriftの実装（変化の検出、クラスタリング）の細部は扱っていない。

## A.7c 定理8(a)の証明（予測とラベルを切り詰めた損失による）【証明】（2026-11-24追記）

A.7b(a)は、定理1（仮定(B)）と命題6（仮定(G)）を組み合わせた概略で、2つの仮定は同時に成り立たなかった。ここでは、予測とラベルの両方を [−B, B] に切り詰めた損失で定理1を当てはめ、正規のラベルがはみ出す分を裾の項として足すことで、仮定(G)のもとで証明する。

**記号**: c_B(u) := max(−B, min(B, u))（[−B, B] への切り詰め）。切り詰めた損失 ℓ̃(ŷ, y) := (c_B(ŷ) − c_B(y))²。真の損失は ℓ(ŷ, y) := (ŷ − y)²。

**アルゴリズム**: 定理1のアルゴリズム（N個のエキスパート、まだ作られていないものは作られたものの重み付き平均を予測）で、各エキスパートの予測を c_B で切り詰め、重みの更新に切り詰めた損失 ℓ̃ を使う。混合の予測は、切り詰めた予測の重み付き平均なので [−B, B] に入る。

**主張**: 仮定(G)（入力 x ~ N(0, I_d)、雑音 ξ ~ N(0, σ²)、入力と独立）、η = 1/(8B²)、N ≥ 2、0 < α ≤ (N−1)/N、B² ≥ v_max とする。v_max := max_z ‖θ*_z‖² + σ²（どの概念のラベルも周辺分布は N(0, ‖θ*_z‖² + σ²) で、分散は v_max 以下）とし、
δ_B := 2φ(B)(3v_max·B + v_max²/B)、φ(B) := exp(−B²/(2v_max))/√(2πv_max) とする。
clientのある区間 [t₀, t₀ + n₀) が、そのclientには初めての概念zに従い、時刻 t₀ より前の同期で、他のclientが正しく割り当てた n_z 件（n_z ≥ d + 2）から最小二乗で学んだ代表のモデル r(z) が届いていて、区間の間 r(z) は変わらないとする。任意の比べる列 e'（各時刻に作られたエキスパートを1つ選ぶ列、切り替え S_{e'} 回、0 ≤ S_{e'} ≤ T − 1）から、区間の外では e' と同じエキスパートを、区間の中では r(z) を選ぶ列 e を作ると、
E[L^mix] ≤ E[L̃^{e'}_{区間の外}] + n₀(σ² + σ²d/(n_z − d − 1)) + R_α(S_{e'}) + (2/η) ln((N−1)(1−α)/α) + T·δ_B。
ここで L^mix は混合の真の損失の和、L̃^{e'}_{区間の外} は区間の外での e' の切り詰めた損失の和（e' の真の損失の和以下）。(2/η) ln((N−1)(1−α)/α) ≤ (2/η)[ln(N−1) + ln(1/α)] が、区間に入って出る切り替え2回分の探す費用。

**証明**:
1. （定理1の適用）予測とラベルを切り詰めたので、全ての予測とラベルが [−B, B] に入り、仮定(B)が損失 ℓ̃ について成り立つ。定理1を e に当てはめ、各系列で L̃^mix ≤ L̃^e + R_α(S_e)。e は長さTの列なので S_e ≤ min(S_{e'} + 2, T − 1) で、定理1の範囲に入る。R_α(s+1) − R_α(s) = (1/η) ln((N−1)(1−α)/α) は α ≤ (N−1)/N のとき0以上なので、S_e ≤ S_{e'} なら R_α(S_e) ≤ R_α(S_{e'})、S_e > S_{e'} なら S_e − S_{e'} ≤ 2 より R_α(S_e) ≤ R_α(S_{e'}) + (2/η) ln((N−1)(1−α)/α)。どちらでも R_α(S_e) ≤ R_α(S_{e'}) + (2/η) ln((N−1)(1−α)/α) ≤ R_α(S_{e'}) + (2/η)[ln(N−1) + ln(1/α)]。
2. （比べる列の損失）c_B は1-リプシッツで単調なので、|c_B(ŷ) − c_B(y)| ≤ |ŷ − y|、よって ℓ̃ ≤ ℓ。区間の中の e は r(z) を使い、E[ℓ̃(r(z)の予測, y)] ≤ E[ℓ(r(z)の予測, y)] = σ² + E‖θ_{r(z)} − θ*_z‖²。r(z) は区間の標本と独立な n_z 件の正規の入力から学んだ最小二乗なので、命題6（Breiman & Freedman 1983 の Theorem 1.1）により σ² + σ²d/(n_z − d − 1)。区間の n₀ 件で足す。区間の外は L̃^e = L̃^{e'}。
3. （切り詰めたラベルと真のラベルの差）混合の予測 ŷ は |ŷ| ≤ B。|y| ≤ B なら ℓ = ℓ̃。|y| > B なら、c := c_B(y) として ℓ(ŷ, y) − ℓ̃(ŷ, y) = (c − y)(2ŷ − y − c) ≤ (|y| − B)(|y| + 3B)。よって 1標本の期待値は E[(|Y| − B)_+(|Y| + 3B)]（Y ~ N(0, v)、v ≤ v_max）以下。これは 2∫_B^∞ (y² + 2By − 3B²)φ_v(y) dy ≤ 2∫_B^∞ (y² + 2By)φ_v(y) dy で、∫_B^∞ yφ_v = vφ_v(B)、∫_B^∞ y²φ_v = v[Bφ_v(B) + P(Y > B)]、ミルズの不等式 P(Y > B) ≤ vφ_v(B)/B から、2φ_v(B)(3vB + v²/B) 以下。g(v) := v^{−1/2} e^{−B²/(2v)}(3vB + v²/B) とすると d ln g/dv = B²/(2v²) − 1/(2v) + (3B + 2v/B)/(3vB + v²/B) で、v ≤ B² なら最初の2項の和は0以上（B²/v ≥ 1）、3つ目の項は正なので、g は v ≤ B² で増える。v ≤ v_max ≤ B² より δ_B 以下。T件で足す。
4. 1〜3を合わせ、期待値を取る（定理1の上界は各系列で成り立つ）。∎

**意味**: 裾の項は B について指数的に小さい（例: B = 3√v_max で δ_B ≈ 0.08·v_max）。一方、R_α は 1/η = 8B² に比例する。B = √(2v_max ln T) 程度に選ぶと、T·δ_B は O(√(v_max ln T)·√v_max) の程度で T に対して増えず、探す費用は O(v_max ln T·(ln N + ln(1/α))) の程度になる。区間の中の比べる相手の損失は σ² + σ²d/(n_z − d − 1) で、他のclientが学んだ件数 n_z が大きいほど σ² に近い。まとめると、混合の期待損失は「区間の外は比べる列 e' の切り詰めた損失（e' の真の損失以下）」＋「区間の中は n₀σ²（雑音）＋ n₀σ²d/(n_z − d − 1)」＋「探す費用（切り替え2回分、O(v_max ln T·(ln N + ln(1/α)))）」＋「裾の項 T·δ_B（上の B で O(v_max√(ln T))）」以下。区間の中の、雑音 n₀σ² を除いた超過に当たる部分は n₀σ²d/(n_z − d − 1) で、これに探す費用と裾の項（系列全体で1回かかる）が加わる。定理8(b)の、自分のデータだけの方式がこの区間で払う雑音を除いた超過の下界 dσ² ln(1 + n₀τ²/σ²) と比べると、n_z が n₀ に比べて十分大きく、n₀ が大きいとき、前者は n₀ について対数より遅く（n_z → ∞ で0へ）、後者は ln n₀ で増える。

**限定と確認**:
- 「区間の間 r(z) は変わらない」とした（同期で r(z) が更新されると、命題6の評価をそのまま使えない。更新は損失を増やさない傾向があるが、証明していない）。
- 数値の確認（主担当）: δ_B の上界の式を、v ∈ {1, 2, 10}、B/√v ∈ {1, 2, 3, 4} の12条件で数値積分の値と比べ、すべて上界以上だった（例: v = 1、B = 3 で δ = 9.58×10⁻³、上界 8.27×10⁻²）。点ごとの不等式 ℓ − ℓ̃ ≤ (|y| − B)_+(|y| + 3B)（|ŷ| ≤ B）は、100万点の乱数ですべて成り立った。
- 混合の予測は、切り詰めた予測の平均で、実装の混合（切り詰めない）とは違う。

## A.9 定理9（真のクラスの損失での Fixed Share。学習率は時間で変わってよい）【証明】

**設定**: N個のエキスパートが、時刻tにクラスの確率の予測 p_{i,t} を出す（過去に依存して学習するモデルでよい）。損失 ℓ_{i,t} := 1 − p_{i,t}(y_t) ∈ [0, 1]。混合は p_t := Σ_i v_{t,i} p_{i,t} で、損失は線形なので ℓ_{mix,t} = Σ_i v_{t,i} ℓ_{i,t}（2クラスの |p − y| も、y ∈ {0, 1} なら同じく線形）。更新は、正規化した重みに exp(−η_t ℓ) を掛けて正規化し（η_t > 0 は、過去と今の損失に依存してよい）、原典の Fixed-share（自分以外の N−1 個へ α/(N−1) ずつ）で分ける。

**主張**: 任意の n 件の区間と、各時刻にエキスパートを1つ選ぶ任意の列 e（切り替え S 回）について、
Σ_{t=1}^{n} (1 − e^{−η_t}) ℓ_{mix,t} ≤ Σ_{t=1}^{n} η_t ℓ_{e_t,t} + ln(1/v_{1,e_1}) + S(ln(N−1) + ln(1/α)) + (n − 1 − S) ln(1/(1−α))。

**証明**: Z_t := Σ_i v_{t,i} e^{−η_t ℓ_{i,t}} とする。x ∈ [0, 1] で e^{−ηx} ≤ 1 − (1 − e^{−η})x（凸性）なので、Z_t ≤ 1 − (1 − e^{−η_t})ℓ_{mix,t} ≤ exp(−(1 − e^{−η_t})ℓ_{mix,t})、つまり −ln Z_t ≥ (1 − e^{−η_t})ℓ_{mix,t}。損失の更新の後の重みは v^post_{t,j} = v_{t,j}e^{−η_t ℓ_{j,t}}/Z_t。分けた後の重みは v_{t+1,j} = (1−α)v^post_{t,j} + (α/(N−1))Σ_{i≠j} v^post_{t,i} なので、v_{t+1,j} ≥ (1−α)v^post_{t,j}、i ≠ j なら v_{t+1,j} ≥ (α/(N−1))v^post_{t,i}（Herbster & Warmuth 1998 の Lemma 3 と同じ）。列 e に沿って n 回の更新と n−1 回の分けを辿ると、ln v^post_{n,e_n} ≥ ln v_{1,e_1} − Σ_t η_t ℓ_{e_t,t} − Σ_t ln Z_t + S ln(α/(N−1)) + (n−1−S) ln(1−α)。左辺は0以下なので、−Σ_t ln Z_t ≤ Σ_t η_t ℓ_{e_t,t} + ln(1/v_{1,e_1}) + S(ln(N−1) + ln(1/α)) + (n−1−S) ln(1/(1−α))。−ln Z_t の下界と合わせる。∎

**系9a（学習率が一定）**: η_t = η なら、L^mix ≤ [η L^e + C_α(S)]/(1 − e^{−η})。ここで C_α(S) := ln(1/v_{1,e_1}) + S(ln(N−1) + ln(1/α)) + (n − 1 − S) ln(1/(1−α))（最初の重みの費用を含む。一様から始めれば ln(1/v_{1,e_1}) = ln N）。0 < η ≤ 1 では η/(1 − e^{−η}) ≤ 1 + η/2 + η²/12 なので、比べる列の損失に掛かる係数は1より少し大きい（η = 1 で 1.58）。二乗損失（A.2）と違い、損失が線形なので「係数1＋対数の費用」の形にはならず、η を √(C/L^e) の程度に選んで、後悔は √(C·L^e) の程度になる。FedHASPの学習率 min(1, √(2 ln N/V_t)) は、この選び方を損失の分散で行う、よく知られた形（同じ形の解析の厳密な当てはめはしていない。A.10(b)）。

**系9b（正解率）**: 予測をクラスの確率の argmax とすると、間違えた時刻では p_t(y_t) ≤ 1/2（真のクラスの確率が最大の確率以下で、2つの和が1以下のため）、つまり ℓ_{mix,t} ≥ 1/2。よって、混合の誤りの数 ≤ 2·L^mix。

## A.10 定理10（FedHASPの実装の重みへの当てはめ）【適用】

**(a) 版の混合**: 実装は、N = 2、η = 2（一定）、α = 1/T（相手へ渡す割合。原典の N = 2 の Fixed-share と同じ式）、最初の重み 1/2、やり直し無し。定理9から、任意の「どちらの版を使うかの列」e（切り替え S 回、全体 n 件）について
L^mix ≤ [2L^e + ln 2 + S ln(1/α) + (n − 1 − S) ln(1/(1−α))]/(1 − e^{−2})。
係数は 2/(1 − e^{−2}) ≈ 2.31 で大きく、保証としては弱い（2つの版の良い方の「2.31倍＋切り替えの費用」以下）。実装の学習率2.0は、手元の診断で0.5〜4の間で精度がほぼ同じだったことから選ばれた値（実装のコメント）で、理論の最適ではない。

**(b) モデルの混合**: やり直しで区切った区間 k ごとに、モデルの集合（N_k 個）は区間の中で変わらない（集合の変化でやり直すため）。区間の中では、実装の更新 v ← (1 − α')v + α'/N_k は、α_k := α'(N_k − 1)/N_k とした原典の Fixed-share と同じ式。学習率 η_t は今の損失に依存するが、定理9はそれを許す。区間の最初の重みは、一様から始まる区間（集合の変化）で 1/N_k、再生で作り直した区間（集約の後）で α'/N_k 以上（分けの後の重みは α'/N_k 以上のため）。よって区間ごとに
Σ_{t∈k} (1 − e^{−η_t}) ℓ_{mix,t} ≤ Σ_{t∈k} η_t ℓ_{e_t,t} + ln(N_k/β_k) + S_k(ln(N_k−1) + ln(1/α_k)) + (n_k − 1 − S_k) ln(1/(1−α_k))
（β_k は一様からなら1、再生の後なら α'）。全体はこれを区間について足したもの。η_t ≤ 1 なので 1 − e^{−η_t} ≥ (1 − e^{−1})η_t で、学習率で重み付けた後悔 Σ_t η_t[(1 − e^{−1})ℓ_{mix,t} − ℓ_{e_t,t}] がやり直しの費用で抑えられる。
- 意味: やり直しのたびに、上界に ln N_k（集合の変化）または ln(N_k/α') = ln N_k + ln T（集約の後の再較正。T = 120 で約4.8 nat）が加わる。集約の間隔Iが短いほど再較正が多く、上界は大きくなる。これは再較正の「理論上の値段」で、再較正が精度を上げるかどうかは理論では決まらない（実験で決める）。
- 限定: 学習率が時間で変わるので、普通の（重みの付かない）損失の和の上界は L^mix_k ≤ (L^e_k + C_k)/((1 − e^{−1})·min_t η_t) までしか言えず、弱い。AdaHedge型の学習率の精密な解析（後悔が √(V ln N) の程度になること）は、この実装の形（Fixed Share、やり直し）について示していない。

**数値の確認**（主担当、製品のクラスそのもの）: `FixedShareWeightController` に、2〜6個のモデル・5〜300件の区間・一様から始める区間と1〜30件の再生の後に始める区間を、30系列×40区間、乱数の損失（最良のモデルが時々入れ替わる）で与え、実装の重みと、実装と同じ式で計算した η_t から、区間ごとの上の不等式の両辺を、2つの比べる列（毎回最良のモデル、ずっと同じモデル）で計算した。2,400組すべてで成り立った（右辺−左辺の最小 0.49）。`SynchronizedAndLocalPredictionMixture` に3,000件×30系列を与え、(a)の不等式が3つの比べる列ですべて成り立った（余裕は大きく、上界は緩い）。

## A.11 系12（系3と定理8を、真のクラスの損失で）【適用】

**仮定（分類の版の概念の違い）**: 数える時刻で、割り当てたモデルが別の概念のもの（κ(a_t) ≠ z_t）なら、過去を条件として E[ℓ(a_t) − ℓ(k*_t)] ≥ Δ_c > 0、同じ概念の重複（κ(a_t) = z_t、a_t ≠ k*_t）なら ≥ −ε_c とする（A.3 の命題2の、分類での形。線形モデルから導いたものではなく、仮定として置く）。

**主張**: 学習率 η ∈ (0, 1] が一定で、N個のエキスパートの集まりが変わらず一様の重みから始める Fixed Share（定理9）について、比べる期間の全体で仮定(O)が成り立つ（各概念の代表 r(z) が最初から作られている）とする。比べる列 k*_t := r(z_t) は、各概念の代表を1つに固定するので、概念が変わる時刻にだけ切り替わり、切り替えの回数はその期間の概念の切り替えの回数 S にちょうど等しい。このとき、
Δ_c·E[n^wrong] − ε_c·E[n^dup] > (η/(1 − e^{−η}) − 1)·E[L^orc] + C_α(S)/(1 − e^{−η})
なら E[L^mix] < E[L^hard]。ここで C_α(S) は系9aの定義（一様から始めるので最初の重みの費用 ln N を含む、比べる期間全体の値）で、A.10(b) の区間ごとの費用 C_k とは別のもの。右辺の第1項は η/2·E[L^orc] の程度で、η を √(C/E[L^orc]) の程度に選ぶと、右辺は √(C·E[L^orc]) の程度。つまり、真のクラスの損失では、混合が固い予測を上回るには、誤った割り当ての費用が「切り替えの費用 C と真の概念のモデルの損失の積の平方根」を超える必要がある（二乗損失の系3では「C」だけでよかった）。

**証明**: 系9aと、仮定から E[L^hard] − E[L^orc] ≥ Δ_c·E[n^wrong] − ε_c·E[n^dup]。∎

**定理8の(a)・(c)の分類の版**: (a) 区間の中で他のclientが学んだ代表 r(z) を使う比べる列への変更の追加の費用は、系9aから [2(ln(N−1) + ln(1/α))]/(1 − e^{−η})（切り替え2回分）と、区間の中の r(z) の損失に掛かる係数 η/(1 − e^{−η})。(c) 固い予測は、仮定から、区間で正しく割り当てるまでの件数 d₀ について Δ_c·E[d₀] を払う。(b)（自分のデータだけの方式の下界）は回帰（二乗損失・正規の事前分布）でだけ示していて、分類の版は無い。

## A.12 命題13（同期の版と手元の版の誤差。命題7の予想の、単純化したモデルでの証明）【証明】

**モデル**: 1つの概念（係数 θ*、等方の入力で予測の超過損失は ‖θ − θ*‖²）を、M個のclientが、勾配に独立な雑音が足される形のSGD e_{t+1} = (1 − η)e_t − ηζ_{m,t}（e = θ − θ*、ζ は平均0・共分散 σ²I_d で、clientと時刻について独立、0 < η < 1）で学び、R件ごとに全clientの e を平均して配る（同期の版は配った値、手元の版はその後の値）。実際のSGDの雑音（入力に掛かる xxᵀ の揺らぎ）を、e に依らない雑音で置き換えた単純化である。

**主張**: 定常状態で（同期の時点で測る）、V_1 := ησ²d/(2 − η)（1 client だけのSGDの定常の E‖e‖²）として、
(i) 同期の版: E‖e_G‖² = V_1/M。
(ii) 同期から k 件後の手元の版: E‖e_L(k)‖² = (1−η)^{2k}·V_1/M + (1 − (1−η)^{2k})·V_1。よって、手元の版の超過は同期の版より (1 − (1−η)^{2k})(1 − 1/M)V_1 だけ大きく、k とともに増える（変化が無い期間は同期の版が良い）。
(iii) 同期の直後に、真の係数が δ だけ動く（概念の変化）と、雑音の平均を除いた偏りは、同期の版が次の同期まで ‖δ‖²、手元の版が (1−η)^{2k}‖δ‖²。手元の版は (1 − (1−η)^{2k})‖δ‖² だけ偏りが小さく、(ii)の分散の差を上回れば手元の版が良い（変化の後は手元の版が良い）。

**証明**: 同期の後 k 件で、各clientは e_L(k) = (1−η)^k e_G − η Σ_{j<k} (1−η)^{k−1−j} ζ_{m,j}。雑音の和の分散は η²σ²d (1 − (1−η)^{2k})/(1 − (1−η)²) = (1 − (1−η)^{2k})V_1（1 − (1−η)² = η(2 − η)）。e_G と雑音は独立なので (ii) は E‖e_G‖² を求めれば出る。R件後の平均は (1−η)^R e_G ＋（M個の独立な雑音の和の平均）で、定常の条件 V_G = (1−η)^{2R}V_G + (1 − (1−η)^{2R})V_1/M から V_G = V_1/M。(iii) は θ* を θ* + δ に置き換えると e の平均が δ だけずれ、手元の版では (1−η)^k 倍に縮むことから。∎

**数値の確認**（主担当、d = 5、σ = 1、4,000本の独立な系列）: (η, M, R) = (0.05, 10, 50)、(0.2, 4, 20)、(0.02, 10, 200) で、E‖e_G‖² の実測は 0.01282・0.13887・0.00504、式 V_1/M は 0.01282・0.13889・0.00505。E‖e_L(k)‖² も k = 1、R/2、R − 1 で式と小数3〜4桁まで一致した。

**意味**: 定理10(a)（版の混合は、2つの版のどちらをいつ使う列にも追いつく）と合わせると、変化の無い期間は分散が1/Mの同期の版へ、変化の直後は偏りの小さい手元の版へ重みが移ることで、混合が両方の良い方に近づく。単純な設定の計測（[定理の記録](linear-concept-pool-theorems-20261124.md)の10章: 差の93〜146%がclient間のばらつき）と、神経網の400 run（[記録](synchronized-prediction-v16-20261124.md): 同期の間隔50では同期の版だけで混合とほぼ同じ、間隔500では混合が両方の版を上回る）は、この形と合う。限定: 加法的な雑音の単純化で、実際のSGD（掛け算の雑音）・Adam・神経網には当てはまらない（向きの説明）。

## A.13 定理8への同期の遅れの追加【適用】

定理8（A.7b・A.7c）は、代表 r(z) が区間の始まり t₀ より前の同期で届いていると仮定した。実際には、他のclientが r(z) を n_z 件学び終えた時刻を t_r とすると、r(z) がこのclientのモデルの集まりに入るのは、max(t₀, t_r) 以降の最初の同期の時刻 t_s で、t_s − max(t₀, t_r) ≤ I（集約の間隔。同期が間隔Iの時刻に起き、r(z) が同期の直後に学び終わると、ちょうどIになりうる）。

**主張**: t_s を「r(z) がこのclientの集まりに入った後の最初の標本の番号」とする（同期の後の標本から使える）。定理8(a)（A.7c）と A.11 の分類の版で、区間 [t₀, t₀ + n₀) を [t_s, t₀ + n₀) に置き換えたものが成り立ち、標本 t₀, …, t_s − 1（t_s − t₀ 件）では比べる列は e' のまま（共有の利得は無い）。共有の利得を、1件あたり g_t := max(0, ℓ_{e'_t,t} − ℓ_{r(z),t})（e' の代わりに r(z) を使ったら減った損失）と定義すると、真のクラスの損失は [0, 1] に入るので g_t ≤ 1 で、失う利得の合計は t_s − t₀ 以下。同期が周期 I で続き、他のclientが区間の始まりより前に学び終えていれば（t_r ≤ t₀）、t_s − t₀ ≤ I。FedHASPの実装では、r(z) が届くとモデルの集合が変わるので、その時点で重みのやり直し（定理10(b)、費用 ln N）も起きる。

**証明**: t < t_s では r(z) がこのclientのエキスパートの集まりに無いので、比べる列に取れない。t ≥ t_s で A.7c・A.11 の議論をそのまま使う。∎

**意味**: 集約の間隔 I は、通信を減らす代わりに、他のclientのモデルを使い始めるまでの遅れ（I 以下）として、未経験の概念の区間の損失に効く。神経網の実験で、間隔500で変化の直後の精度が下がることと合う向き（直接の確認はしていない）。

## A.15 学習率が時間で変わる重みの更新の、普通の後悔について【適用＋反例】

**FedHASPの更新の位置づけ**: 実装は、正規化した重みに exp(−η_t ℓ_t) を掛けていく（A.10(b)）。学習率が変わっても過去の損失は観測した時の学習率のまま残り、共有が無ければ重みは exp(−Σ_s η_s ℓ_s) に比例する。調査資料によれば、これは学習率が時間で変わる鏡像降下（dynamic online mirror descent）と同じ形で、この形の普通の後悔について √(V ln N) の程度の上界を示した文献は見つからず、一般の dynamic mirror descent には線形の後悔の反例がある（Orabona & Pál, Scale-Free Online Learning, TCS 2018, Theorem 5。Fang, Harvey, Portella & Friedlander, ICML 2020 / JMLR 2022。いずれも調査資料による、原典未照合）。FedHASPの学習率の式そのものについての反例も、文献には見つからなかった（調査資料による）。教科書の分散に適応する方式（Cesa-Bianchi, Mansour & Stoltz 2007 の Weighted Majority、AdaHedge）は、今の学習率を過去の累積の損失全体に掛け直す形で、FedHASPとは違う（調査資料による、原典未照合）。

**主張（A）（学習率で重み付けた2次の上界）**: 定理9と同じ設定で η_t ≤ 1 とする。任意の比べる列 e（切り替え S 回、n 件の区間）について
Σ_t η_t (ℓ_{mix,t} − ℓ_{e_t,t}) ≤ ln(1/v_{1,e_1}) + S(ln(N−1) + ln(1/α)) + (n−1−S) ln(1/(1−α)) + (e − 2) Σ_t η_t² σ_t²
（σ_t² := Σ_i v_{t,i}(ℓ_{i,t} − ℓ_{mix,t})² は重みでの損失の分散）。

**証明**: 定理9の証明の −ln Z_t の評価だけを替える。y ≤ 1 で e^y ≤ 1 + y + (e − 2)y² なので、y = −η_t(ℓ_{i,t} − ℓ_{mix,t}) ≤ 1（損失が [0, 1] で η_t ≤ 1 なら成り立つ十分条件）から Σ_i v_{t,i} e^{−η_t(ℓ_{i,t} − ℓ_{mix,t})} ≤ 1 + (e − 2)η_t²σ_t²（1次の項は重みの平均で0）。よって ln Z_t ≤ −η_t ℓ_{mix,t} + (e − 2)η_t²σ_t²。残りは定理9と同じ鎖。∎（共有の無い場合の同じ形の不等式は、調査資料にも独自の導出として書かれている。）

**主張（B）（固定の共有率では、最良の固定のモデルに対する後悔は系列の長さに比例する）**: 共有率 α' > 0 を固定した一様への共有（実装の形）で、モデル1の損失がいつも0、ほかがいつも1なら、共有の後の重みは v_{t,1} ≤ 1 − α' + α'/N なので ℓ_{mix,t} ≥ α'(1 − 1/N)、後悔は (n − 1)α'(1 − 1/N) 以上。一方、重みでの分散の累積は α'n の程度なので、√(V ln N) は √(α'n ln N) の程度で、後悔のほうが速く増える。

**証明**: 共有の式 v ← (1−α')v + α'/N で、v_1 ≤ 1 なら v_1 ≤ (1−α') + α'/N。モデル1以外の重みの和が α'(1 − 1/N) 以上で、損失は1。∎（調査資料の独自の反例と同じ。）

**数値の確認（実装）**: 製品の `FixedShareWeightController` に、前半はモデル0、後半はモデル1が損失0となる列（N = 2）を与えた。T = 120（実装の既定）では、混合の損失は500件で11.7、5,000件で135と系列の長さに比例して増え（切り替え1回の列の損失は0）、共有をほぼ無くす（T = 10⁹）と22で止まった。主張（B）と同じ向き。

**まとめ（数値をそのまま述べる）**: FedHASPのモデルの混合の重みについて、示せる保証は学習率で重み付けた後悔（定理10(b)、主張（A））で、普通の後悔の √(V ln N) の程度の上界は、文献にも無く、固定の共有率のもとでは最良の固定のモデルに対しては成り立たない（主張（B））。切り替える比べる列に対しては、Fixed Share の上界の (n − 1 − S) ln(1/(1−α)) の項（1件あたり約α）が、共有の値段として残る。FedHASPは集約のたびに重みを作り直すので、この値段と、学習率で重み付けることの偏りは、集約の間隔の中に限られる（A.10(b)）。普通の後悔の上界を実装に当てはめるには、学習率が変わるときに重みを付け直す変更が要る（[IMPROVE-034](improvement-candidates/improve-034-re-exponentiate-fixed-share-weights-when-learning-rate-changes.md)。未検証）。

## A.16 命題14（分類で、自分のデータだけで学ぶ方式の累積の下界。固定の事前分布）【証明】

**なぜ新しく証明するか**: Massart & Nédélec (2006, Ann. Statist. 34(5)) の Theorem 4 は、VC次元 V のクラスと Massart の雑音の条件 h のもとで、標本 n 件の最小最大の超過リスクが κ[V/(nh) ∧ √(V/n)] 以上だと示す（主担当が原典で確かめた。証明は Assouad の補題で、難しい分布の族の点の質量を p = 2/(9nh²) と n に依存して選び、h ≥ √((V−1)/n) で R_n ≥ (V−1)/(54nh) を得る）。難しい分布の族が n に依存するので、この下界を n について足して累積の下界にすることはできない（調査資料の注意。主担当も証明の形から同意する）。そこで、n に依らない固定の事前分布で、各時刻の下界を示して足す。

**設定**: 入力 x は d 個のセル {1, …, d} から一様に独立に来る。概念は θ ∈ {0, 1}^d で、事前分布は一様（各成分が独立に1/2）。ラベルは確率 (1 + h)/2 で y = θ_x、確率 (1 − h)/2 で反転（Massart の雑音、0 < h ≤ 1/2）。clientは新しい概念の区間で、自分のこの区間の過去の標本（と、θ と独立な他の情報）だけから、次の標本のクラスの確率 p を出す。損失は真のクラスの損失 1 − p_y（2クラスでは |p − y|。決めたラベルを出すなら0-1損失）。

**主張**: どの方式でも、区間の最初の n₀ 件の、ベイズ最適の損失に対する累積の期待超過は、n₀ ≥ 3d/(32h²) + 1 なら 3d/(256h) 以上、n₀ がそれより小さければ n₀h/8 以上。したがって、どの方式についても、入力・雑音（と方式の乱数）についての期待値でこの値以上を払う θ が存在する。

**証明**:
1. 1件の超過: セル x の条件付きのベイズの損失は (1 − h)/2。予測が真のラベル θ_x の反対のクラスに確率質量 w を置くと、期待の損失は (1 − h)/2 + h·w。つまり超過は h·w で、p について線形。過去のデータで条件付けると、θ_x の事後分布のもとでの最良は w ∈ {0, 1}（多数の向き）で、その時の期待の超過は h·P(多数の向きが θ_x と違う | データ)。
2. 2点の判定の下界: 事前分布が積で、セル x の過去の k 件の観測だけが θ_x の情報を持つ（他のセルの観測、x の出方は θ_x と独立）。k 件の観測から θ_x ∈ {0, 1}（一様）を当てるベイズの誤りの確率は (1/2)(1 − TV(P_0^k, P_1^k))（Le Cam）。P_0、P_1 は Bernoulli((1 ± h)/2) で、KL(P_0‖P_1) = h ln((1 + h)/(1 − h)) ≤ 8h²/3（h ≤ 1/2 で ln((1+h)/(1−h)) ≤ 2h/(1 − h²) ≤ 8h/3）。Pinsker の不等式から TV ≤ √(k·KL/2) ≤ 2h√(k/3)。よって k ≤ k* := 3/(16h²) なら誤りの確率は 1/4 以上で、1件の期待の超過は h/4 以上。
3. 観測の数: t 件目（t = 1, 2, …）でセル x_t の過去の観測の数 k_t は二項分布 Bin(t − 1, 1/d)。マルコフの不等式で P(k_t > k*) ≤ (t − 1)/(d·k*) なので、t − 1 ≤ d·k*/2 = 3d/(32h²) なら P(k_t ≤ k*) ≥ 1/2。このとき t 件目の期待の超過は (1/2)(h/4) = h/8 以上。
4. 足す: t = 1, …, min(n₀, ⌊3d/(32h²)⌋ + 1) の各件が h/8 以上で、その件数は min(n₀, 3d/(32h²)) 以上。∎

**数値の確認**（主担当、各2,000回）: ベイズ最適（セルごとの多数決）の累積の期待超過は、(d, h, n₀) = (10, 0.2, 24)、(50, 0.1, 469)、(20, 0.4, 12) で 2.05・19.86・2.17、下界は 0.59・5.86・0.59。すべて下界以上（下界は約3.4〜3.7倍緩い）。

**限定**: 下界は d/h の程度で、log n は付かない（この有限のセルの族では、学び終えた後の誤りは指数的に減るため）。log n の付く形（Massart & Nédélec の Theorem 5 の、豊かなクラスの族）や、log loss での (d/2) log n（Clarke & Barron 1990、調査資料による、原典未照合）とは別。モデルは単純化したもので、神経網の学習の費用ではない。

## A.17 命題15（確率的な差があるとき、共有のモデルを混合で使う費用は区間の長さに依らない）と、定理8の分類の版【証明】

**設定**: 区間の n₀ 件で、N 個のモデル（他のclientが学んだ代表 r を含む）は固定で、標本は独立同分布。各モデルの真のクラスの損失 ℓ_{i,t} ∈ [0, 1] について、i ≠ r なら E[ℓ_{i,t} − ℓ_{r,t}] ≥ Δ_c > 0。混合は一様から始め、学習率 η ∈ (0, Δ_c] が一定、共有は無い（α = 0）。

**主張**: E[Σ_t (ℓ_{mix,t} − ℓ_{r,t})] ≤ (N − 1)/(1 − e^{−ηΔ_c/2})（≤ (N − 1)(1 + 2/(ηΔ_c))）。区間の長さ n₀ に依らない。

**証明**: D_{i,t} := Σ_{s<t}(ℓ_{i,s} − ℓ_{r,s})。共有が無く一様から始めるので v_{t,i}/v_{t,r} = e^{−ηD_{i,t}}、v_{t,r} ≤ 1 から v_{t,i} ≤ e^{−ηD_{i,t}}。t 件目の超過は Σ_{i≠r} v_{t,i}(ℓ_{i,t} − ℓ_{r,t}) ≤ Σ_{i≠r} v_{t,i}。増分 ℓ_{i,s} − ℓ_{r,s} ∈ [−1, 1] は独立同分布で平均 Δ_c 以上なので、Hoeffding の補題から E e^{−η(ℓ_i − ℓ_r)} ≤ exp(−ηΔ_c + η²/2) ≤ exp(−ηΔ_c/2)（η ≤ Δ_c）。よって E[v_{t,i}] ≤ e^{−ηΔ_c(t−1)/2}。t と i ≠ r について足す。∎

**数値の確認**（主担当、各2,000回、n₀ = 3,000）: (N, Δ_c, η) = (5, 0.2, 0.2)、(10, 0.1, 0.05)、(3, 0.3, 0.3) で、混合−r の期待値は 9.59・48.29・4.42、上界は 202・3,605・45.5。すべて上界以下（上界は緩い）。

**定理8の分類の版（命題14・15と系12の組合せ）**: 新しい概念の区間で、
- 自分のデータだけで学ぶ方式は、どの方式でも、累積の期待超過 3d/(256h) 以上を払う（命題14のモデル）。
- 他のclientが学んだ代表 r が届いていて、他のモデルとの損失の差が Δ_c なら、混合（共有なし、一定の η ≤ Δ_c）が r に対して払う追加は (N − 1)(1 + 2/(ηΔ_c)) 以下で、区間の長さに依らない（命題15）。r 自身の超過は、r の学習の量（他のclientの件数）で決まる。
- 固い予測は、正しく割り当てるまでの件数 d₀ について Δ_c·E[d₀] を払う（系12の仮定）。
**限定**: 命題15は共有の無い一定の学習率の混合で、FedHASPの実装（共有率 1/T、時間で変わる学習率、やり直し）とは違う。共有があると、悪いモデルに重みが残り、1件あたり約 α' の追加の費用が加わる（A.15 の主張（B）と同じ理由。証明はしていない）。命題14のモデル（有限のセル、Massart の雑音）と命題15の差 Δ_c の関係は結び付けていない。二乗損失の版（定理8、A.7c）の「探す費用」が log N の程度だったのに対し、真のクラスの損失では N の程度（差 Δ_c を使う確率的な議論のため。log loss のような混ぜられる損失なら log N にできる、調査資料による）。

## A.19 定理16（log loss・学習率1の Fixed Share は、どの「モデルを選ぶ列」にも係数1で追いつく）【適用】

**設定**: N個のエキスパートが、時刻tにクラスの確率の予測 p_{i,t} を出す（過去に依存して学習するモデルでよい。予測はラベルを見る前に決まる）。log loss は λ_{i,t} := −ln p_{i,t}(y_t)（p_{i,t}(y_t) > 0 とする）。混合は p_t := Σ_i v_{t,i} p_{i,t}、その損失は λ_{mix,t} := −ln p_t(y_t)。更新は v^post_{t,i} := v_{t,i} p_{i,t}(y_t)/Z_t（Z_t := Σ_i v_{t,i} p_{i,t}(y_t)。学習率1の指数の重みの更新と同じ）の後、原典の Fixed-share（自分以外の N−1 個へ α/(N−1) ずつ）で分ける。N ≥ 2、0 < α < 1 とする（N = 1 の時刻は、混合がそのモデルと同じで後悔0の自明な場合。研究ツールもモデルが1個の時刻は重みを更新しない）。

**主張**: 任意の n 件の区間と、各時刻にエキスパートを1つ選ぶ任意の列 e（切り替え S 回）について、
L^mix_log := Σ_{t=1}^{n} λ_{mix,t} ≤ Σ_{t=1}^{n} λ_{e_t,t} + C_α(S)。
ここで C_α(S) = ln(1/v_{1,e_1}) + S(ln(N−1) + ln(1/α)) + (n − 1 − S) ln(1/(1−α))（系9aと同じ定義。一様から始めれば第1項は ln N）。

**証明**: Z_t = Σ_i v_{t,i} p_{i,t}(y_t) = p_t(y_t) なので、−ln Z_t = λ_{mix,t}（定理9の証明の −ln Z_t の評価が、不等式ではなく等式になる）。分けた後の重みには下界 v_{t+1,j} ≥ (1−α)v^post_{t,j} と、i ≠ j なら v_{t+1,j} ≥ (α/(N−1))v^post_{t,i} がある（Herbster & Warmuth 1998 の Lemma 3）。これを列 e に沿って辿ると、
ln v^post_{n,e_n} ≥ ln v_{1,e_1} − Σ_t λ_{e_t,t} − Σ_t ln Z_t + S ln(α/(N−1)) + (n−1−S) ln(1−α)。
左辺は0以下なので、Σ_t λ_{mix,t} = −Σ_t ln Z_t ≤ Σ_t λ_{e_t,t} + C_α(S)。∎

**位置づけ**: log loss と確率の重み付き平均の予測は (1, 1)-realizable である。これは Herbster & Warmuth (1998) の Theorem 1 の log loss の場合で、定理1と同じ原典の上界を log loss に当てはめたもの。定理9（真のクラスの損失）とは次の3点が違う。
- (1) 比べる列の損失に掛かる係数が1（系9aでは η/(1 − e^{−η}) > 1、η = 1 で 1.58）。
- (2) 学習率を損失に合わせて選ぶ必要が無い（学習率1で一定）。後悔は √(C·L^e) の程度ではなく、C_α(S) そのもの。
- (3) A.15 では、製品の更新（時間で変わる学習率）には普通の後悔の上界が言えず、学習率で重み付けた後悔（定理10(b)、A.15の主張（A））までしか示せなかった。log loss の更新は学習率が一定なので、普通の後悔の上界がそのまま成り立つ（IMPROVE-034 の付け直しは要らない）。

ただし、比べる量は log loss で、真のクラスの損失や正解率ではない（系16a・16c）。

**系16a（正解率）**: 予測を混合の確率の argmax とする。argmax の予測が真のクラスと違う時刻では、真のクラス以外に真のクラス以上の確率を持つクラスがあり、2つの確率の和は1以下なので p_t(y_t) ≤ 1/2（系9bと同じ理由）、つまり λ_{mix,t} ≥ ln 2。よって、混合の誤りの数 ≤ L^mix_log/ln 2 ≤ (Σ_t λ_{e_t,t} + C_α(S))/ln 2。

**系16b（研究ツールの実装への当てはめ）**: 区間の中でモデルの集合（N_k 個）が変わらず、区間の全時刻で全てのモデルの p_{i,t}(y_t) ≥ 10⁻¹² だとする（下限が働かない）。このとき、実装の更新は、定理16の更新に α_k := α'(N_k − 1)/N_k を代入したものと同じ式になる（共有の式の対応は A.10(b) と同じ）。区間の最初の重みは、一様から始まる区間（集合の変化）で 1/N_k、再生で作り直した区間（集約の後）で α'/N_k 以上（A.10(b) と同じ）。この下界を β_k/N_k と書く（β_k は一様からなら1、再生の後なら α'）。モデルが1個の区間は後悔0なので除く。よって、やり直しで区切った N_k ≥ 2 の区間 k ごとに
Σ_{t∈k} λ_{mix,t} ≤ Σ_{t∈k} λ_{e_t,t} + ln(N_k/β_k) + S_k(ln(N_k−1) + ln(1/α_k)) + (n_k − 1 − S_k) ln(1/(1−α_k))。
- 学習率が一定なので、区間について足すと、全体の log loss の普通の後悔の上界になる。定理10(b)の、学習率で重み付けた形の限定は無い。
- やり直しの値段は定理10(b)と同じく、区間ごとに ln N_k、または ln N_k + ln T。
- 下限（10⁻¹²）が働いた時刻は、この当てはめの外になる。A.21で、下限の代わりに平滑化した形を扱う。

**系16c（真のクラスの損失との関係）**: 0 < p ≤ 1 で 1 − p ≤ −ln p ≤ (1 − p)/p。
- 左の不等式から、混合の真のクラスの損失 Σ_t (1 − p_t(y_t)) は L^mix_log 以下で、定理16の右辺で抑えられる。
- 右の不等式から、比べる列が全時刻で p_{e_t,t}(y_t) ≥ p_min を満たすなら、Σ_t λ_{e_t,t} ≤ L^e/p_min（L^e は比べる列の真のクラスの損失）。
- つまり、比べる列が自信を持って当てている（p_min が1に近い）なら、log loss の更新の保証は「L^e/p_min ＋ C_α(S)」になり、真のクラスの損失の更新の保証（系9a）より係数も費用の形も良い。
- 比べる列が自信を持って外す時刻があると、その時刻の λ が大きく、保証は弱くなる（下限と平滑化の役割、A.21）。

**数値の確認**（主担当、研究ツールの更新そのもの）: 製品の `FixedShareWeightController` に研究ツールの log loss の更新を差し込み、系列を300本与えた。各系列は2〜6個のモデル・2〜4クラス・20〜600件で、1〜5区間に分かれ、区間ごとに真のクラスの確率を上げたモデルが入れ替わる乱数の確率を使った。全ての確率は10⁻⁶以上なので、下限は働かない。
- (1) 重みは、独立に書いた「ベイズの更新＋一様への共有」と全時刻で一致した（差の最大 1.1×10⁻¹⁵）。
- (2) 定理16の不等式は、2つの比べる列（ずっと同じ最良のモデル、区間ごとの最良のモデル）の600組すべてで成り立った。右辺−左辺の最小は 0.005 で、log loss では上界が等号に近い。
- (3) 系16aの誤りの数の不等式も、300本すべてで成り立った。
- 確認のscriptはGit管理外（主担当の作業用）。

## A.20 注: 保証はモデルの学習と割り当ての方式に依らない【既知の性質の当てはめ】

定理16（と定理1・定理9）は、エキスパートの予測とラベルの関係に仮定を置かない、個々の系列についての上界である。エキスパートの予測がラベルを見る前に決まりさえすれば、各モデルがどのデータで学習したか（固い割り当ての誤り、検出の遅れ、統合を含む）に依らずに成り立つ。

したがって、検出・割り当てを単純にした構成でも、柔らかい予測の保証は同じ形で残る。例えば[積み上げの記録](core-component-ladder-v16-20261119.md)の節3の最小形（ADWIN＋γ、MDLなし、共有部なし）がそうである。割り当ての質は主として比べる列の損失 Σ λ_{e_t,t}（良いモデルが作られているか）を通して効く。実装に当てはめるときは、モデルの数（ln N_k）や、モデルの集合の変化・集約の後の再生の回数も、区間ごとのやり直しの費用（系16b）に入る。

同じ記録では、固い割り当ての質が下がるほど柔らかい予測の増分が大きかった（柔らかい予測−固い予測が、最小形で +2.5〜3.0pp、細部を残した形で +1.2〜2.0pp）。この結果は上の形と矛盾しない（説明として証明したものではない）。

ベイズの解釈: 「どのエキスパートが正しいか」を隠れた状態とし、遷移が「確率 1−α で留まり、α/(N−1) ずつ他へ移る」マルコフ連鎖を考える。学習率1の log loss の Fixed Share の重みは、この隠れマルコフモデルの前向きの計算（フィルタ）の事後確率そのもので、L^mix_log はその周辺尤度の −ln に等しい（Herbster & Warmuth 1998 の考え方。Vovk 1999 "Derandomizing stochastic prediction strategies" や、Koolen & de Rooij の切り替えの事前分布の研究でも同じ見方をする。いずれも原典未照合）。定理16の右辺は、比べる列 e のこの事前分布での確率の −ln を、比べる列の尤度に足したものの上界である。

## A.21 命題17（確率を一様と混ぜる平滑化の値段）【証明】

**動機**: log loss には上限が無い。あるモデルが真のクラスに確率ほぼ0を出すと、1件でその重みがほぼ0になる。共有があるので重みは次の時刻に α/(N−1) 程度まで戻るが、上界の比べる列の損失 λ_{e_t,t} が大きくなる。研究ツールは確率に下限 10⁻¹² を置いたが、これは定理16の形に入らない（系16b）。

**設定**: δ ∈ (0, 1)、クラスの数を K とする。各エキスパートの予測を q_{i,t} := (1 − δ)p_{i,t} + δ/K に替え、定理16の更新と混合を q で行う。混合の予測は q_t := Σ_i v_{t,i} q_{i,t} = (1 − δ)p̄_t + δ/K（p̄_t := Σ_i v_{t,i} p_{i,t}）。

**主張**:
- (1) 各時刻の log loss は ln(K/δ) 以下。
- (2) 任意の比べる列 e（切り替え S 回、n 件）について、Σ_t −ln q_t(y_t) ≤ Σ_t −ln p_{e_t,t}(y_t) + n ln(1/(1 − δ)) + C_α(S)。
- (3) q_t の argmax は p̄_t の argmax と同じ。よって、平滑化しない重み付き平均 p̄_t（重みは q で更新したもの）の誤りの数も、(2)の右辺/ln 2 以下。

**証明**: (1) q_{i,t}(y) ≥ δ/K。(2) 定理16を q に当てはめ、−ln q_{e_t,t}(y_t) ≤ −ln((1 − δ)p_{e_t,t}(y_t)) = −ln p_{e_t,t}(y_t) + ln(1/(1 − δ)) を使う。(3) q_t は p̄_t の正の定数倍に定数を足したもので、クラスの順序が同じ。argmax の予測が真のクラスと違う時刻では、真のクラス以外に真のクラス以上の q_t の確率を持つクラスがあり、q_t も確率の分布なので q_t(y_t) ≤ 1/2、つまり −ln q_t(y_t) ≥ ln 2。誤りの数は Σ_t −ln q_t(y_t)/ln 2 以下で、(2) から主張が従う。∎

**選び方**:
- n ln(1/(1 − δ)) ≈ nδ なので、δ = 1/n なら値段は約1 nat で、比べる列が確率0を出す時刻の損失は ln(Kn) 以下になる。
- 系列の長さが分からないときは δ = 1/T（共有率と同じ時間の尺度、T = 120）とすると、1件あたりの値段は約 1/T で、共有の値段 (n−1−S) ln(1/(1−α)) と同じ程度。
- 研究ツールの下限 10⁻¹² は δ をほぼ0にした形で、値段はほぼ0だが、確率ほぼ0の時刻の損失は約 27.6 nat まで大きくなりうる。
- 実験で δ を変えた比較はしていない。rotmnist4 の落ち着いた後の期間の小さな低下（−0.11〜−0.17pp）がこれと関係するかは未確認。

## A.22 MDLによる割り当ての選択との対応（製品の既定の構成について）【概略】

最小形には MDL が無いので、この節は製品の既定（基準版16）の構成についての見通しである。MDL の選択そのものは新規性として主張しない（論文のリポジトリのメモ `notes/mdl-positioning.md` の結論）。ここで述べるのは、重みを log loss で更新すると、固い割り当てと柔らかい予測を同じ確率モデルの2つの計算として読める、という組み合わせの一貫性である。

**実装の確認（主担当が読んだ箇所）**: `methods/fedsda/training_data_assignment/minimum_description_length_assignment_selection.py` の `select_assignment_by_minimum_description_length`。警報の時点で、保留の標本と警報の標本の列（最大31件）について、次の仮説の符号長の最短を選ぶ。
- (i) 全部を、現在のモデルの log loss で符号化する。
- (ii) 前の n−k 件を現在のモデル、後の k 件を保有モデル m の log loss で符号化し、切り替えの符号長を足す。
- (iii) 後の k 件を、新しいモデルの予測的符号長（2つの学習者の短い方＋ln 2）で符号化し、切り替えの符号長を足す。

切り替えの符号長は `compute_switching_code_length` で −ln(1/T) + ln(行き先の数＋1)（行き先は現在のモデル以外の保有モデル、＋1は新しいモデル）。切り替えの確率 1/T は、実装のコメント（`runtime/fedsda_run_client.py`）の通り「予測の重み（Fixed-Share）の分け合いの割合と同じ」。

**対応**: 保有モデルが N 個（現在のモデルを含む）のとき、製品の共有の式 v ← (1 − α')v + α'/N（α' = 1/T）では、ある時刻に特定の別のモデルへ移る確率は α'/N で、符号長は ln T + ln N。MDL の切り替えの符号長は ln T + ln((N − 1) + 1) = ln T + ln N で、同じ値になる。MDL が省いているのは留まる時刻の値段 ln(1/(1 − α' + α'/N))（1件あたり約 1/T）だけで、仮説(i)と(ii)(iii)の差に約 1/T の違いを生むだけである。したがって、重みを log loss・学習率1で更新するとき、次のように読める。
- 柔らかい予測（定理16の混合）は、遷移が共有の式で与えられる隠れマルコフモデルの、前向きの計算（全ての経路で混ぜた予測）。
- MDL の選択は、同じ遷移の確率のもとで、窓の中で「現在のモデルから始まり、高々1回切り替わる」経路のうち、符号長が最短の経路を選ぶ計算（Viterbi の、窓と切り替えの回数を限った版）。留まる値段の約 1/T の違いを除く。
- 新しいモデルの仮説は、窓の途中から加わるエキスパート（specialists、眠る専門家）の予測的符号長に当たる。ln 2 は、2つの学習者に一様な事前分布を置いたときの形（「短い方＋ln 2」は、2つの混合の符号長以上の上界）。

**まだ確かめていない点・違う点**:
- (1) 製品の既定の重みは、真のクラスの損失 1 − p_y と時間で変わる学習率で更新する。今の既定ではこの対応は成り立たず、log loss の更新を採ったときにだけ成り立つ。
- (2) MDL は警報のときだけ、長さ31以下の窓で、固い割り当ての現在のモデルから始まる経路だけを調べる。全期間の最良の経路ではない。
- (3) 新しいモデルの予測的符号長は、窓の標本で学びながら符号化する学習者のもの。重みの側の「新しいモデルが入ったら一様へやり直す」扱い（系16b）とは、参入の事前分布が違う。重みの側を specialists の形にそろえると、参入の値段が ln(1/α_new) になる見込み（[記録](fedhasp-prediction-weight-rules-20261125.md)の節3の案1）。
- (4) 割り当てた後に各モデルを学習するので、経路の尤度は固定のエキスパートのものではない。定理16は予測がラベルの前に決まれば成り立つが、MAP の経路を選ぶことの最適性の主張は無い。
- (5) MDL の行き先は、現在のモデル以外の保有モデルのうち、損失の統計を持つものだけ（`runtime/alarm_interval_minimum_description_length_selection.py` の `destination_model_ids`）。符号長が ln T + ln N で一致するのは、保有モデルの全部が損失の統計を持つときである。また、重みの側の N は予測に使う保有モデルの数で、MDL の「＋1」は新しいモデルなので、一致は数の上のもので、行き先の集合は同じではない。

**価値の見積もり**: 論文の主張として使えるのは、「固い割り当て（MDL）と柔らかい予測（log loss の Fixed Share）が、同じ切り替えの事前分布（共有率 1/T）の Viterbi と前向きの計算に当たる」という説明の一貫性で、精度の新しい保証ではない。単純な構成で実験し直す方針（担当教授の指摘）とは向きが違うので、優先度は低い。最小形で log loss の重みが効くと分かった後に、MDL を戻す価値があるかを決める材料として残す。

## A.24 定理18（学習率 η ≤ 1 の log loss の Fixed Share）【証明】

**設定**: 定理16と同じ（N ≥ 2、0 < α < 1、p_{i,t}(y_t) > 0）。更新だけを v^post_{t,i} := v_{t,i} p_{i,t}(y_t)^η / Z^η_t（Z^η_t := Σ_i v_{t,i} p_{i,t}(y_t)^η、0 < η ≤ 1）に替え、原典の Fixed-share で分ける。予測は定理16と同じく確率の重み付き平均 p_t := Σ_i v_{t,i} p_{i,t}。

**主張**: 任意の列 e（切り替え S 回）について、L^mix_log ≤ Σ_t λ_{e_t,t} + C_α(S)/η。

**証明**: x ↦ x^η（0 < η ≤ 1）は凹なので、Jensen の不等式で Z^η_t = Σ_i v_{t,i} p_{i,t}(y_t)^η ≤ (Σ_i v_{t,i} p_{i,t}(y_t))^η = p_t(y_t)^η。よって λ_{mix,t} = −ln p_t(y_t) ≤ −(1/η) ln Z^η_t。分けた後の重みの下界（Herbster & Warmuth 1998 の Lemma 3）を列 e に沿って辿ると、定理16の証明で λ を ηλ に替えた式
ln v^post_{n,e_n} ≥ ln v_{1,e_1} − η Σ_t λ_{e_t,t} − Σ_t ln Z^η_t + S ln(α/(N−1)) + (n−1−S) ln(1−α)
が成り立つ。左辺は0以下なので −Σ_t ln Z^η_t ≤ η Σ_t λ_{e_t,t} + C_α(S)。両辺を η で割り、上の不等式と合わせる。∎

- η = 1 で定理16に戻る。η を下げると費用は 1/η 倍になる（log loss の上界としては弱くなる）。
- 研究ツールの実装への当てはめは系16bと同じ（区間ごとに α_k := α'(N_k − 1)/N_k、最初の重みの下界 β_k/N_k、下限が働かない時刻に限る）。区間 k の費用は (ln(N_k/β_k) + S_k(ln(N_k−1) + ln(1/α_k)) + (n_k − 1 − S_k) ln(1/(1−α_k)))/η。
- 学習率を下げる狙いは、log loss の上界ではなく、安定した期間に重みを1つのモデルへ寄せすぎないこと（A.27）。その効果は、この定理の保証の外にある。

## A.25 定理19（学習率の候補を混ぜる二段の混合）【証明】

**設定**: 下の層は、学習率 η_1, …, η_K（0 < η_k ≤ 1）の K 個の Fixed Share（同じ N 個のエキスパート）。下の層 k の予測を q_{k,t} := Σ_i w_{k,t,i} p_{i,t} とする。上の層は、この K 個の予測をエキスパートとする log loss・学習率1の Fixed Share（重み u_{t,k}、原典の分け方で α_top）。最終の予測は p_t := Σ_k u_{t,k} q_{k,t} = Σ_i (Σ_k u_{t,k} w_{k,t,i}) p_{i,t}。K ≥ 2、0 < α_top < 1、q_{k,t}(y_t) > 0 とする。

**主張**: 下の層を選ぶ任意の列 κ（切り替え S' 回）について、L^mix_log ≤ Σ_t −ln q_{κ_t,t}(y_t) + C^top_{α_top}(S')。ここで C^top は、C_α(S) の N を K に、α を α_top に替えたもの。特に κ を1つの層 k に固定し、定理18を合わせると、任意の列 e（切り替え S 回）について
L^mix_log ≤ min_k [Σ_t λ_{e_t,t} + C_α(S)/η_k] + ln K + (n − 1) ln(1/(1 − α_top))。

**証明**: q_{k,t} はラベルを見る前に決まる（過去だけに依る）確率の予測なので、上の層は定理16の設定そのもの（エキスパートが下の層）。定理16を上の層に当てはめると前半が出る。κ を層 k に固定すると S' = 0 で、C^top = ln K + (n − 1) ln(1/(1 − α_top))。下の層 k に定理18を当てはめて足す。∎

- 実装への当てはめ: 上の層の共有の式 u ← (1 − α')u + α'/K は、原典の α_top = α'(K − 1)/K に当たる（A.10(b)と同じ対応）。モデルの集合の変化・証拠の消去で両方の層を一様から作り直すので、系16bと同じく、やり直しで区切った区間ごとに成り立つ。上の層の確率に掛かる下限 10⁻¹² が働かないときに限る。
- 費用の形: 上の層の共有の値段 (n − 1) ln(1/(1 − α_top)) は区間の長さに比例する（α' = 1/120、K = 3 なら1件あたり約 0.0056 nat）。代わりに、前半の主張で、変化の前後で別の学習率の層を選ぶ列（切り替え S' 回）と比べられる。「変化の直後は η = 1、安定した期間は小さい η」を、警報や手作りの条件なしに、log loss の後悔の保証つきで選ぶ形になる。
- ln K の費用は、どの学習率が良いかを事前に決めない値段である。

## A.26 命題20（区間の後悔: 変化の直後の回復の速さ）【証明】

**設定**: 学習率1の log loss の Fixed Share で、研究ツールの分け方 v ← (1 − α')v + α'/N を使う。モデルの集合が変わらない区間（やり直しで区切った区間の1つ）の中の、任意の時刻の区間 [a, b] を考える。

**主張**: 任意のモデル i について、Σ_{t=a}^{b} λ_{mix,t} ≤ Σ_{t=a}^{b} λ_{i,t} + ln(N/α') + (b − a) ln(1/(1 − α'))。

**証明**: 分けた後の重みはどれも α'/N 以上で、区間の最初の重み（一様）は 1/N ≥ α'/N。よって v_{a,i} ≥ α'/N（再生で作り直した区間の最初でも、再生の更新の後なら同じ）。i に留まる列に沿って、v^post_{t,i} = v_{t,i} p_{i,t}(y_t)/p_t(y_t) と v_{t+1,i} ≥ (1 − α')v^post_{t,i} を a から b まで辿ると、
ln v^post_{b,i} ≥ ln v_{a,i} + Σ_{t=a}^{b} (λ_{mix,t} − λ_{i,t}) + (b − a) ln(1 − α')。
左辺は0以下。∎

- 意味: 概念の変化が時刻 a に起きたとする。変化の後に最も良いモデル i に対して、混合の余分な log loss は、どの長さの区間でも ln(N/α') ＋ 1件あたり ln(1/(1 − α')) 以下。N = 3、α' = 1/120 なら ln 360 ≈ 5.9 nat ＋ 1件あたり約 0.0084 nat。系16aと同じ理由で、区間の誤りの数は (Σ_{t∈[a,b]} λ_{i,t} + 5.9 + 0.0084(b − a))/ln 2 以下。変化の直後の50件では、新しいモデルの log loss に約 6.3 nat を足した分しか遅れない。
- 対比（概略）: 有界の損失 ℓ ∈ [0, 1] と一定の学習率 η の Fixed Share では、同じ鎖から Σ_{[a,b]} ℓ_mix ≤ (η Σ_{[a,b]} ℓ_i + ln(N/α') + (b − a) ln(1/(1 − α')))/(1 − e^{−η}) になる（定理9の区間の版）。η が小さいと費用 ln(N/α')/(1 − e^{−η}) ≈ ln(N/α')/η が大きく、回復が遅い。製品の学習率は √(2 ln N / V) で累積の分散 V とともに小さくなるので、安定した期間が長いほど、変化の後の回復が遅れる向きになる。ただし製品の学習率は時間で変わるので、この形がそのまま成り立つわけではない（A.15）。
- 実験との対応: 最小形で、log loss の利得は変化の後の0〜50標本に集中した（+7.51pp、50〜100は +0.41pp）。製品の既定の上でも同じ形（+3.88pp）。命題20の「固定の費用で追いつく」形と同じ向きで、上界から差の大きさは言えない。

## A.27 注: 保証の範囲の限界（安定した期間の小さな損について）【既知の性質】

- 定理16・18・19と命題20の比べる相手は「各時刻に1つのモデルを選ぶ列」で、モデルを混ぜた予測（凸結合）ではない。同じくらいの質のモデルを混ぜることの利得は、これらの保証の外にある。
- 最小形の安定した期間の小さな損（−0.11〜−0.19pp）は、この範囲の外の量なので、定理と矛盾しない。学習率1の log loss は、同じくらいの質のモデルの間で、確率の比の揺れをそのまま重みに映し、重みを1つのモデルへ寄せる（実験の診断: 画像のデータで1位の入替が増え、有効モデル数が減った。記録の節7）。これは仮説で、モデルごとの確率の記録で切り分ける（記録の節8の計画）。
- 凸結合と比べる保証として、log loss では Cover のユニバーサル・ポートフォリオ型の混合（重みの単体の上の一様な事前分布で混ぜる）が、最良の固定の凸結合に (N − 1) ln(n + 1) 程度の後悔で追いつくことが知られている（文献は原典未照合）。切り替えと組み合わせる形は重く、ここでは当てはめていない。
