## A.1 設定

client c ∈ {1, …, C} は時刻 t = 1, …, T に、入力 x と実数のラベル y を受け取る（理論は回帰の二乗損失で述べる。分類の精度への翻訳はしていない）。clientが時刻tに従う概念を z_t、概念zの真の係数を θ*_z、概念の違いを Δ := min_{z≠z'} ‖θ*_z − θ*_{z'}‖² とする。概念の列はあらかじめ決まっている（学習者の振る舞いに依らない）とし、clientあたりの切り替えの回数を S とする。

各clientはモデルの集まりを持ち、時刻tにモデルkは係数 θ_{k,t} を持つ。θ_{k,t} は時刻tのラベルを見る前の情報だけで決まる（学習の途中でよい）。モデルkが表す概念 κ(k) は、学習の標本の多数派の概念とする。予測の方式は3つ:
- 固い予測: 割り当てたモデル a_t の予測 f_{a_t,t}(x_t)。割り当ての列の切り替えの回数を S^a とする（同じ概念の重複したモデルの間の行き来も数える）。
- 真の概念のモデル（比べる相手。実際には使えない）: 各概念zに代表のモデル r(z) を1つ固定し（同じ概念の重複があっても代表は1つ）、k*_t := r(z_t) として f_{k*_t,t}(x_t)。この列の切り替えの回数は S。
- 混合: 下のFixed Share。

仮定（結果ごとにどれを使うかを書く）:
- (B) 有界性: 全ての予測とラベルが [−B, B] に入る（例: 入力が有界、係数を半径Θの球へ射影、雑音が有界）。
- (L) 線形・等方: E[x] = 0、E[xxᵀ] = I。ラベルは y = ⟨θ*_{z_t}, x⟩ + ξ で、ξ は入力と独立に平均0・分散σ²。このとき E[(⟨θ, x⟩ − y)²] = σ² + ‖θ − θ*_z‖²。
- (G) 正規: (L) に加えて、x ~ N(0, I_d)、ξ ~ N(0, σ²)。
- (E) ε-精度: 考える時刻で、全てのモデルが ‖θ_{k,t} − θ*_{κ(k)}‖² ≤ ε を満たす。
- (O) 代表の存在: 考える時刻で、各概念 z_t の代表のモデル r(z_t) が作られていて、κ(r(z)) = z。（全体で初めての概念の直後など、代表がまだ無い期間は(O)が成り立たない。そこでは真の概念のモデルとの比較は定義せず、定理1を、実際に比べる列の切り替えの回数 S_orc で使う。）

## A.2 定理1（混合は、どの「モデルを選ぶ列」にも対数の費用で追いつく）【適用】

**アルゴリズム**: モデルの数の上限を N とし、N個のエキスパートを最初から置く。まだ作られていないモデルに当たるエキスパートは、その時刻の「作られたモデルだけの重み付き平均」を予測する。統合では、統合先iの予測は統合後の係数による予測に変わり、統合元jはその後iと同じ予測をする。混合は全エキスパートの重み付き平均を予測し、損失で重みに exp(−η·損失) を掛け、原典の Fixed-share（各エキスパートが自分以外の N−1 個へ α/(N−1) ずつ配る）を行う。

**主張**: 仮定(B)、η = 1/(8B²)、0 < α < 1 のとき、任意の系列と、各時刻にエキスパートを1つ選ぶ任意の列 e（切り替え S_e 回）について

L^mix ≤ L^e + R_α(S_e)、　R_α(s) := (1/η)[ln N + s(ln(N−1) + ln(1/α)) + (T−1−s) ln(1/(1−α))]。

特に、仮定(O)が全時刻で成り立つとき、同じアルゴリズムで同時に L^mix ≤ min{ L^hard + R_α(S^a), L^orc + R_α(S) }（(O)が一部の期間で成り立たないなら、その期間に使う列を含めた実際の切り替えの回数 S_orc で R_α(S_orc)）。α = S/(T−1)（1 ≤ S ≤ T−2。αが(0,1)に入る範囲）とすると R_α(S) ≤ (1/η)[ln N + S ln(N−1) + S ln((T−1)/S) + S]。切り替えの無い列（S_e = 0）と比べるときは、R_α(0) = (1/η)[ln N + (T−1) ln(1/(1−α))]。

**証明**: Herbster & Warmuth (1998) の Theorem 1 は、結果とエキスパートの予測が [0, 1] で、損失と予測関数が (c, η)-realizable（η = 1/c）のとき、任意の系列と任意の分割について上の形の上界を与える（エキスパートの予測と結果の関係に仮定を置かないので、過去に依存して学習するモデルの予測でよい）。二乗損失と重み付き平均の予測は (2, 1/2)-realizable（原典 Figure 2）で、[−B, B] を [0, 1] へ線形に写すと損失が 4B² 倍になるので η = 1/(8B²)。まだ作られていないエキスパートの予測を、作られたものの重み付き平均 q とすると、全体の重み付き平均は (Σ_作られた w f + W_未 q)/(W_作 + W_未) = q となり、自己無撞着で、ラベルを見る前に決まり、[−B, B] に入る。統合の後のjの予測もラベルの前に決まる。よって原典の上界がそのまま当てはまる。α = S/(T−1) のときの値は原典の Corollary 1（(T−1−S) ln(1 + S/(T−1−S)) ≤ S を使う）。∎

**注**: (1) 実装（実験の研究ツール・製品）とは次が違うので、定理は実装をそのまま保証しない: 作られていないモデルを重みの計算から外し、作られた時点で重み α'/保有数 で入れる。統合でjの重みをiへ足してjを消す。予測を [−B, B] に切り詰めない。混合の学習率を調整して η = 1/(8B²) より大きくする。共有の式 v ← (1−α')v + α'/N は、Nが一定の間は原典の式と α = α'(N−1)/N で同じ。(2) 理論値の η では上界は実測より桁で大きく、実験で確かめたのは形だけ（A.8）。

## A.3 命題2（固い予測の費用）と系3（混合が固い予測を上回る条件）【適用】

**命題2**: 仮定(L)、(E)、(O)のもとで（数える時刻の全てで成り立つとき）、n^wrong := #{t : κ(a_t) ≠ z_t}（別の概念のモデルへ割り当てた標本の数）、n^dup := #{t : κ(a_t) = z_t, a_t ≠ k*_t}（同じ概念の別のモデル＝重複へ割り当てた標本の数）とすると、
E[L^hard] − E[L^orc] ≥ (Δ − 2√(Δε))·E[n^wrong] − ε·E[n^dup]。

**証明**: (L)から、過去を条件とした1標本の期待損失は σ² + ‖θ − θ*_{z_t}‖²。κ(a_t) ≠ z_t の時刻では、三角不等式と(E)より ‖θ_{a_t} − θ*_{z_t}‖ ≥ √Δ − √ε（ε < Δ のとき）、また ‖θ_{k*_t} − θ*_{z_t}‖² ≤ ε なので、差は (√Δ − √ε)² − ε = Δ − 2√(Δε) 以上。重複の時刻は、固い予測の期待損失が σ² 以上、真の概念のモデルが σ² + ε 以下なので、差は −ε 以上。a_t = k*_t の時刻は差が0。条件付き期待値を足す。∎

**系3**: 仮定(B)(L)(E)(O)が全時刻で成り立ち、ε < Δ/4 のもとで、(Δ − 2√(Δε))·E[n^wrong] − ε·E[n^dup] > R_α(S) なら E[L^mix] < E[L^hard]（n^dup は同じ概念の別のモデルへ割り当てた標本の数）。切り替えのたびに、その後のd件が別の概念のモデルへ割り当てられるなら n^wrong ≥ S·d で、α = S/(T−1) のとき、おおよそ d > (ln(N−1) + ln(e(T−1)/S))/(η(Δ − 2√(Δε))) を超える遅れで混合が上回る。遅れも誤りも無ければ（n^wrong = 0）、固い予測は真の概念のモデルと一致し、混合は最大 R_α(S) だけ悪くなりうる。

**証明**: 定理1は各系列で成り立つので期待値を取れる。命題2と合わせる。∎

**注**: (B)と(L)を同時に満たすには、有界で E[xxᵀ] = I の入力（例: 各成分が ±1）と有界な雑音を考える。(E)は学び始めのモデルや汚れたモデルでは成り立たないので、系3はモデルが学習できた後の期間についての主張である。

## A.4 補題4（誤った学習による汚れ）【適用】

**主張**: 仮定(L)の概念の混合で、モデルが概念zの標本と、割合 ρ_j で概念jの標本から学ぶとき（Σ_j ρ_j = ρ）、母集団の最小二乗解は θ̄ = (1−ρ)θ*_z + Σ_j ρ_j θ*_j、概念zでの余分な損失は ‖Σ_j ρ_j(θ*_j − θ*_z)‖²。1つの概念jだけなら ρ²‖θ*_j − θ*_z‖²。

**証明**: 各概念で E[xxᵀ] = I、E[xy] = θ*_z なので、混合の正規方程式の解は重み付き平均。概念zでの損失は σ² + ‖θ̄ − θ*_z‖²。∎

**注**: 標本が無限の母集団の解についての主張で、有限標本・SGDの保証ではない。共有では、モデルIDごとに全clientの標本で学ぶので、ρは全clientの誤った学習の割合になる。

## A.5 命題5（窓の検定で選び間違える確率と、まとまる条件）【適用】

**仮定**: (G)。窓のw件は1つの概念zから独立に来て、窓の間モデルを固定とみなす。モデルkの残差の分散を v_k := σ² + ‖θ_k − θ*_z‖² とする（残差は N(0, v_k)、窓の平均損失 L̄_k は v_k·χ²_w/w）。

**主張**: (a) v_k < v_j、g := v_j − v_k のとき、P(L̄_j ≤ L̄_k) ≤ 2 exp(−w g²/(25 v_j²))。保有するN個のモデルについて和を取ると、正しいモデル以外を選ぶ確率は 2(N−1) exp(−w g_min²/(25 v_max²)) 以下。(b) 概念zのモデルがまだ無く、今のモデルjが別の概念のとき、新しいモデルを作る閾値τに対して v_j(1 + 2√(u/w) + 2u/w) ≤ τ なら、確率 1 − e^{−u} 以上で L̄_j ≤ τ となり、新しいモデルは作られない（zはjにまとまる）。

**証明**: Laurent & Massart (2000) の Lemma 1 の系 (4.3) P(U − w ≥ 2√(wu) + 2u) ≤ e^{−u}、(4.4) P(w − U ≥ 2√(wu)) ≤ e^{−u}（Uは自由度wのχ²）を使う。ρ := √(u/w) とする。(a) ρ = g/(5v_j) と置くと ρ ≤ 1/5 なので 2ρ² ≤ ρ、また 3v_k + 2v_j ≤ 5v_j より v_k(1 + 3ρ) ≤ v_j(1 − 2ρ)。L̄_k ≥ v_k(1 + 2ρ + 2ρ²) と L̄_j ≤ v_j(1 − 2ρ) のどちらも起きなければ L̄_k < L̄_j。2つの事象の確率は e^{−u} 以下で、u = w g²/(25 v_j²)。(b) は (4.3) をそのまま使う。∎

**注**: (b)は十分条件。v_j ≈ σ² + Δ、τ = σ²(1 + z√(2/w)) を入れ、Δ ≪ σ² で u/w の項を無視すると、おおよそ w ≲ 2z²σ⁴/Δ² のときまとまる形になる（必要条件ではない）。

## A.6 命題6（モデルの共有の利得）【既知＋適用】

**主張**: 仮定(G)で、概念zの標本 n 件（n ≥ d + 2）から切片なしの最小二乗で学んだモデルの、次の独立な標本での期待の超過損失は σ²d/(n − d − 1)（n ≤ d + 1 では無限大）。共有で、他のclientがすでに正しく割り当てた n_z 件を学んでいれば、自分の n 件目の後の期待の超過損失は σ²d/(n_z + n − d − 1) で、共有なしの σ²d/(n − d − 1) より小さい。全体で初めての概念（n_z = 0）では差が無い。

**証明**: Breiman & Freedman (1983) の Theorem 1.1（全ての変数を使う場合）。Belkin, Hsu & Xu の Theorem 1 にも同じ式がある。導出は、Xを条件とした推定の誤差の共分散 σ²(XᵀX)⁻¹ と、逆Wishartの平均 E[(XᵀX)⁻¹] = I/(n − d − 1) による。∎

**注**: 同期の遅れと汚れ（補題4）は無いとした。定理1の比べる列は「そのclientが持つモデルの集まり」から選ぶので、共有で学習済みのモデルが集まりに入れば、割り当てが遅れていても、混合はそのモデルの損失に R_α の費用で追いつく。固い予測は、正しいモデルへ割り当てるまで共有の利得を受け取れない（命題2の n^wrong の期間）。

## A.7 命題7（同期の版と手元の版の混合）【適用＋予想】

**主張（適用）**: 2つの版（同期の時点のモデルと、手元で更新したモデル）を2つのエキスパートとする Fixed Share は、定理1（N = 2）により、どちらの版をいつ使うかの任意の切り替えの列に R_α の費用で追いつく。さらに二乗損失では恒等式 ℓ(Σ v_i f_i) = Σ v_i ℓ(f_i) − Σ v_i (f_i − p)²（p = Σ v_i f_i）が成り立ち、混ぜた予測は2つの損失の重み付き平均より、2つの食い違いの分だけ良い。

**予想（概略）**: 線形・定常・clientのSGDの雑音が互いに独立なとき、全clientで平均した同期の版の誤差の分散は、1 clientの分散のおよそ 1/C。手元の版は同期からの件数だけ自分の雑音を足す。したがって、同期が頻繁で変化が無い期間は同期の版が良く、変化の直後は（同期の版が最大Iだけ古いので）手元の版が良い。混合はその良い方に追いつく。

## A.7b 定理8（自分は未経験だが他のclientが学んだ概念での利得と、柔らかい重みの役割）（2026-11-24追記）

ユーザーの指摘（2026-11-24）: 連合学習では、普通のオンライン学習やエキスパート統合と違い、「自分はまだ経験していないが正解のモデル」を持てる。モデルを共有する他の方式（FedDriftなど）も持てるが、FedHASPはそれを柔らかい重みで、割り当てが決まる前から使う点が違う。定理8はこれを (a) 共有の上界、(b) 単独の学習者の下界、(c) 固い割り当ての費用 の3つに分けて述べる。

**設定**: clientのある区間 [t₀, t₀ + n₀) が、そのclientには初めての概念zに従う。他のclientがzを学び、時刻 t₀ より前の同期で、その代表のモデル r(z)（他のclientの正しく割り当てた n_z 件で学んだもの）がこのclientに届いている（仮定(O)がこの区間で成り立つ）。

**(a) 共有の上界【概略。証明は A.7c】**: 定理1は系列全体の上界なので、区間だけを切り出さず、比べる列の変更として述べる。任意の比べる列 e'（各時刻に作られたエキスパートを1つ選ぶ列、切り替え S_{e'} 回）から、区間の外では e' と同じエキスパートを、区間の中では r(z) を選ぶ列 e を作る（(O)より r(z) は区間の間作られている）。e の切り替えの回数は S_e ≤ min(S_{e'} + 2, T − 1)（区間の始まりと終わりで最大2回増え、長さTの列なので T − 1 回を超えない）。定理1を e に当てはめると L^mix ≤ L^e + R_α(S_e)。α ≤ (N−1)/N のとき R_α(s+1) − R_α(s) = (1/η) ln((N−1)(1−α)/α) ≥ 0 で、S_e − S_{e'} ≤ 2 なので、R_α(S_e) ≤ R_α(S_{e'}) + (2/η) ln((N−1)(1−α)/α) ≤ R_α(S_{e'}) + (2/η)[ln(N−1) + ln(1/α)]。つまり、区間の外は e' と同じ損失のまま、区間の中で r(z) の損失に追いつくための追加の費用は、切り替え2回分（「N個の候補から正しいモデルを探す費用」）で抑えられる。最初の費用 (1/η) ln N と、毎時刻の共有の費用 (T−1−s)(1/η) ln(1/(1−α)) は、e' と e のどちらを比べても同じだけかかる系列全体の費用で、この区間に固有のものではない。区間の中の L^e は r(z) 自身の損失で、r(z) が他のclientの n_z 件（n_z ≥ d + 2）から学んだ最小二乗で区間の間変わらないとき、仮定(G)のもとで超過分の期待値は n₀σ²d/(n_z − d − 1)（命題6）で、n_z が大きいほど0に近い（A.7cで証明する範囲。区間の中で r(z) が学び続ける場合は証明していない）。

**(b) 単独の学習者の下界【証明】**: 仮定(G)に加えて、概念zの係数 θ*_z が事前分布 N(0, τ²I_d) から、他の全ての概念の係数・入力・雑音と独立に選ばれるとする。このclientが自分の過去の標本だけから予測を作る任意の方式（予測は今の入力と自分の過去の標本の関数）は、区間の最初の n₀ 件で
E[Σ_{i=0}^{n₀−1} ((ŷ_i − y_i)² − σ²)] ≥ dσ² ln(1 + n₀τ²/σ²)
を払う（期待値は事前分布・入力・雑音と、方式が乱数を使うならその乱数について）。したがって、どの方式についても、入力・雑音（と方式の乱数）についての期待値でこの値以上を払う θ*_z が存在する（最悪の場合の下界。個々の雑音の系列での損失を保証するものではない）。区間の始まりは θ*_z と独立に決まるとする。

**証明**: 区間のi件目の予測の時点で、θ*_z について情報を持つのは、この区間の最初のi件だけ（他の標本は θ*_z と独立）。正規の事前分布と正規の雑音から、θ*_z の事後分布は正規で、共分散は Σ_i = (I/τ² + X_iᵀX_i/σ²)⁻¹（X_i はこの区間の最初のi件の入力）。新しい入力 x は過去と独立で、⟨θ*_z, x⟩ の、過去と x を与えたときの最良の予測（2乗誤差で）は事後平均で、その誤差の期待値は E[xᵀΣ_i x] = E[tr Σ_i]（E[xxᵀ] = I）。どの予測もこれ以上の誤差を持ち、雑音は独立なので、1件の期待の超過損失は E[tr Σ_i] 以上。行列の逆のトレースは正定値行列について凸なので、Jensenの不等式で E[tr Σ_i] ≥ tr((I/τ² + E[X_iᵀX_i]/σ²)⁻¹) = d/(1/τ² + i/σ²) = dσ²τ²/(σ² + iτ²)。a := σ²/τ² とおき、Σ_{i=0}^{n₀−1} 1/(a + i) ≥ ∫₀^{n₀} dx/(a + x) = ln(1 + n₀/a) を使う。∎

**(b)の数値の確認**（主担当、d = 10、σ = 1、各400回）: ベイズ最適（事後平均。自分のデータだけの方式の中で最良）の累積の超過損失は、τ ∈ {0.3, 1, 3}・n₀ ∈ {20, 100, 500} の9条件すべてで下界以上だった（例: τ = 0.3・n₀ = 100で 27.68 ± 0.86 対 下界 23.03。τ = 3・n₀ = 100で 556.06 ± 28.64 対 68.04）。τが大きいと下界は緩い（Jensenの不等式が学び始めの数件で緩いため）。

**(c) 固い割り当ての費用【適用】**: 仮定(L)(E)(O)のもとで、この区間で、割り当てが r(z)（またはzを表す重複）に移るまでに d₀ 件かかる固い予測は、命題2により、この区間だけで (Δ − 2√(Δε))·E[d₀] − （重複の項）以上を、真の概念のモデルより多く払う。共有のモデルがあっても、正しく割り当てるまではその利得を受け取れない。割り当てを集約の時点でだけ変える方式（FedDrift型）では、d₀ は、区間の始まりから次の集約までの件数以上になる（区間の始まりの位置による。最大で約 I。区間の始まりが集約の周期の中で一様に分布すると仮定したときの平均は約 I/2 で、これは平均の値で、個々の区間の下界ではない）。

**意味**:
- (a)と(b)の比: 連合学習でモデルを共有する方式は、他のclientが十分に学んでいれば（n_z が大きい）、未経験の概念で「探す費用」（log N の程度）しか払わない。自分のデータだけの方式は、どのようなアルゴリズムでも「学ぶ費用」（dσ² log(n₀τ²/σ²) の程度）を、未経験の概念ごとに払う。これは、普通のオンライン学習・エキスパート統合（エキスパートは外から与えられるか、自分のデータで学ぶ）には無い、連合学習でモデルの集まりを共有することの利点で、FedDrift型の方式も持つ。
- (a)と(c)の比: 共有のモデルを使い始めるまでの遅れの費用は、固い割り当てでは概念の違いΔに比例して遅れの件数だけかかり、柔らかい重み（混合）では切り替えの費用（log の程度）で済む。FedHASPに固有なのはこの部分で、「自分は未経験の正解のモデル」を、割り当てが決まる前から重みに応じて使う。
- 実験との対応: 線形回帰の設定で、共有の利得は「自分には初めてで他のclientが経験済み」の区間に集中し、遅れ・誤りがあると固い予測ではその利得が縮み、混合では保たれた（[実験の記録](linear-concept-pool-theory-20261124.md)の2・3章）。神経網でも、混合の効果は他のclientが経験済みの区間で大きかった（[1クライアントの予備実験](fedhasp-single-client-pilot-v16.md)の仮説1の切り分け）。

**限定**: (a)は定理1（仮定(B)）と命題6（仮定(G)）を組み合わせた概略で、2つの仮定は同時には成り立たない（正規の入力は有界でない）。厳密にするには、切り詰めた予測での命題6の評価が要る（未着手）。(b)は事前分布の平均の下界で、事前分布の選び方（τ）に依る。実験の概念の係数（直交する方向に大きさs）は正規の事前分布から選んだものではない。(c)のFedDrift型の遅れは、集約の時点でだけ割り当てを変えるという単純化で、FedDriftの実装（変化の検出、クラスタリング）の細部は扱っていない。

## A.7c 定理8(a)の証明（予測とラベルを切り詰めた損失による）【証明】（2026-11-24追記）

A.7b(a)は、定理1（仮定(B)）と命題6（仮定(G)）を組み合わせた概略で、2つの仮定は同時に成り立たなかった。ここでは、予測とラベルの両方を [−B, B] に切り詰めた損失で定理1を当てはめ、正規のラベルがはみ出す分を裾の項として足すことで、仮定(G)のもとで証明する。

**記号**: c_B(u) := max(−B, min(B, u))（[−B, B] への切り詰め）。切り詰めた損失 ℓ̃(ŷ, y) := (c_B(ŷ) − c_B(y))²。真の損失は ℓ(ŷ, y) := (ŷ − y)²。

**アルゴリズム**: 定理1のアルゴリズム（N個のエキスパート、まだ作られていないものは作られたものの重み付き平均を予測）で、各エキスパートの予測を c_B で切り詰め、重みの更新に切り詰めた損失 ℓ̃ を使う。混合の予測は、切り詰めた予測の重み付き平均なので [−B, B] に入る。

**主張**: 仮定(G)（入力 x ~ N(0, I_d)、雑音 ξ ~ N(0, σ²)、入力と独立）、η = 1/(8B²)、N ≥ 2、0 < α ≤ (N−1)/N、B² ≥ v_max とする。v_max := max_z ‖θ*_z‖² + σ²（どの概念のラベルも周辺分布は N(0, ‖θ*_z‖² + σ²) で、分散は v_max 以下）とし、
δ_B := 2φ(B)(3v_max·B + v_max²/B)、φ(B) := exp(−B²/(2v_max))/√(2πv_max) とする。
clientのある区間 [t₀, t₀ + n₀) が、そのclientには初めての概念zに従い、時刻 t₀ より前の同期で、他のclientが正しく割り当てた n_z 件（n_z ≥ d + 2）から最小二乗で学んだ代表のモデル r(z) が届いていて、区間の間 r(z) は変わらないとする。任意の比べる列 e'（各時刻に作られたエキスパートを1つ選ぶ列、切り替え S_{e'} 回、0 ≤ S_{e'} ≤ T − 1）から、区間の外では e' と同じエキスパートを、区間の中では r(z) を選ぶ列 e を作ると、
E[L^mix] ≤ E[L̃^{e'}_{区間の外}] + n₀(σ² + σ²d/(n_z − d − 1)) + R_α(S_{e'}) + (2/η) ln((N−1)(1−α)/α) + T·δ_B。
ここで L^mix は混合の真の損失の和、L̃^{e'}_{区間の外} は区間の外での e' の切り詰めた損失の和（e' の真の損失の和以下）。(2/η) ln((N−1)(1−α)/α) ≤ (2/η)[ln(N−1) + ln(1/α)] が、区間に入って出る切り替え2回分の探す費用。

**証明**:
1. （定理1の適用）予測とラベルを切り詰めたので、全ての予測とラベルが [−B, B] に入り、仮定(B)が損失 ℓ̃ について成り立つ。定理1を e に当てはめ、各系列で L̃^mix ≤ L̃^e + R_α(S_e)。e は長さTの列なので S_e ≤ min(S_{e'} + 2, T − 1) で、定理1の範囲に入る。R_α(s+1) − R_α(s) = (1/η) ln((N−1)(1−α)/α) は α ≤ (N−1)/N のとき0以上なので、S_e ≤ S_{e'} なら R_α(S_e) ≤ R_α(S_{e'})、S_e > S_{e'} なら S_e − S_{e'} ≤ 2 より R_α(S_e) ≤ R_α(S_{e'}) + (2/η) ln((N−1)(1−α)/α)。どちらでも R_α(S_e) ≤ R_α(S_{e'}) + (2/η) ln((N−1)(1−α)/α) ≤ R_α(S_{e'}) + (2/η)[ln(N−1) + ln(1/α)]。
2. （比べる列の損失）c_B は1-リプシッツで単調なので、|c_B(ŷ) − c_B(y)| ≤ |ŷ − y|、よって ℓ̃ ≤ ℓ。区間の中の e は r(z) を使い、E[ℓ̃(r(z)の予測, y)] ≤ E[ℓ(r(z)の予測, y)] = σ² + E‖θ_{r(z)} − θ*_z‖²。r(z) は区間の標本と独立な n_z 件の正規の入力から学んだ最小二乗なので、命題6（Breiman & Freedman 1983 の Theorem 1.1）により σ² + σ²d/(n_z − d − 1)。区間の n₀ 件で足す。区間の外は L̃^e = L̃^{e'}。
3. （切り詰めたラベルと真のラベルの差）混合の予測 ŷ は |ŷ| ≤ B。|y| ≤ B なら ℓ = ℓ̃。|y| > B なら、c := c_B(y) として ℓ(ŷ, y) − ℓ̃(ŷ, y) = (c − y)(2ŷ − y − c) ≤ (|y| − B)(|y| + 3B)。よって 1標本の期待値は E[(|Y| − B)_+(|Y| + 3B)]（Y ~ N(0, v)、v ≤ v_max）以下。これは 2∫_B^∞ (y² + 2By − 3B²)φ_v(y) dy ≤ 2∫_B^∞ (y² + 2By)φ_v(y) dy で、∫_B^∞ yφ_v = vφ_v(B)、∫_B^∞ y²φ_v = v[Bφ_v(B) + P(Y > B)]、ミルズの不等式 P(Y > B) ≤ vφ_v(B)/B から、2φ_v(B)(3vB + v²/B) 以下。g(v) := v^{−1/2} e^{−B²/(2v)}(3vB + v²/B) とすると d ln g/dv = B²/(2v²) − 1/(2v) + (3B + 2v/B)/(3vB + v²/B) で、v ≤ B² なら最初の2項の和は0以上（B²/v ≥ 1）、3つ目の項は正なので、g は v ≤ B² で増える。v ≤ v_max ≤ B² より δ_B 以下。T件で足す。
4. 1〜3を合わせ、期待値を取る（定理1の上界は各系列で成り立つ）。∎

**意味**: 裾の項は B について指数的に小さい（例: B = 3√v_max で δ_B ≈ 0.08·v_max）。一方、R_α は 1/η = 8B² に比例する。B = √(2v_max ln T) 程度に選ぶと、T·δ_B は O(√(v_max ln T)·√v_max) の程度で T に対して増えず、探す費用は O(v_max ln T·(ln N + ln(1/α))) の程度になる。区間の中の比べる相手の損失は σ² + σ²d/(n_z − d − 1) で、他のclientが学んだ件数 n_z が大きいほど σ² に近い。まとめると、混合の期待損失は「区間の外は比べる列 e' の切り詰めた損失（e' の真の損失以下）」＋「区間の中は n₀σ²（雑音）＋ n₀σ²d/(n_z − d − 1)」＋「探す費用（切り替え2回分、O(v_max ln T·(ln N + ln(1/α)))）」＋「裾の項 T·δ_B（上の B で O(v_max√(ln T))）」以下。区間の中の、雑音 n₀σ² を除いた超過に当たる部分は n₀σ²d/(n_z − d − 1) で、これに探す費用と裾の項（系列全体で1回かかる）が加わる。定理8(b)の、自分のデータだけの方式がこの区間で払う雑音を除いた超過の下界 dσ² ln(1 + n₀τ²/σ²) と比べると、n_z が n₀ に比べて十分大きく、n₀ が大きいとき、前者は n₀ について対数より遅く（n_z → ∞ で0へ）、後者は ln n₀ で増える。

**限定と確認**:
- 「区間の間 r(z) は変わらない」とした（同期で r(z) が更新されると、命題6の評価をそのまま使えない。更新は損失を増やさない傾向があるが、証明していない）。
- 数値の確認（主担当）: δ_B の上界の式を、v ∈ {1, 2, 10}、B/√v ∈ {1, 2, 3, 4} の12条件で数値積分の値と比べ、すべて上界以上だった（例: v = 1、B = 3 で δ = 9.58×10⁻³、上界 8.27×10⁻²）。点ごとの不等式 ℓ − ℓ̃ ≤ (|y| − B)_+(|y| + 3B)（|ŷ| ≤ B）は、100万点の乱数ですべて成り立った。
- 混合の予測は、切り詰めた予測の平均で、実装の混合（切り詰めない）とは違う。
