# FedDriftの集約の間隔による低下の内訳（変化の直後とそれ以外、2026-11-01）

- 目的: 論文の図1で、間隔500でFedDriftがFedAvg並みに下がる理由を確かめる（ユーザーの問い: FedDriftの論文の設定ならここまで下がらないはず）。新しい実験はせず、既存のrawを再集計した。
- 集計: 各クライアントの真のコンセプトが変わった標本から $I$ 標本（集約の間隔）を「直後」とし、累積の精度を「直後」と「それ以外」に分けた（10 seedの平均）。FedHASPは基準版16の既定（6データは`results/fedsda-component-ablation-v16/20261029_231413_core-components-v16-seeds0-9/fedsda`、新しい4データは値が同じ版15の`fedsda-every-sample-change-interval-search`）、FedDriftは6データが調整したδ、新しい4データが公式の既定のδ、FedAvgは集約ごとの形。一時script: Claudeのscratchpadの`post_change_accuracy.py`（Git管理外）。

| データ・間隔 | 直後の標本の割合 | FedHASP 全体/直後/それ以外 | FedDrift 全体/直後/それ以外 | FedAvg 全体/直後/それ以外 |
|---|---:|---|---|---|
| SINE2・50 | 4.8% | 98.9 / 89.7 / 99.3 | 94.5 / 14.5 / 98.6 | 57.6 / 45.1 / 58.2 |
| SINE2・500 | 43.5% | 98.2 / 97.0 / 99.1 | 61.1 / 20.5 / 92.4 | 57.3 / 46.1 / 65.7 |
| MNIST4・50 | 4.7% | 94.9 / 86.6 / 95.3 | 91.8 / 71.0 / 92.9 | 83.1 / 81.0 / 83.2 |
| MNIST4・500 | 42.4% | 91.7 / 90.7 / 92.5 | 82.0 / 79.5 / 83.9 | 81.9 / 80.0 / 83.3 |
| ROTMNIST4・50 | 4.7% | 92.3 / 76.6 / 93.1 | 89.7 / 30.8 / 92.6 | 83.3 / 73.2 / 83.8 |
| ROTMNIST4・500 | 42.4% | 87.8 / 84.0 / 90.5 | 69.1 / 41.9 / 89.1 | 73.5 / 64.6 / 80.0 |

- 読み: FedDriftの低下の大部分は、変化の直後の $I$ 標本で起きる。変化の後、次の検出まで古いモデルで予測するためで、SINE2（ラベルの反転）では直後の精度が14〜21%（偶然より低い）。間隔500では、変化が約1000標本に1回起きるので、直後の標本が全体の約43%になる。FedDriftの「それ以外」の精度も、間隔を延ばすと下がる（SINE2 98.6→92.4、MNIST4 92.9→83.9）。FedHASPは、直後でも76.6〜97.0%を保つ。
- FedDriftの論文の設定との違い（`FedDrift_paper/expt.tex`と付録）: 変化は500標本の時刻の境目でだけ起き、各クライアントの変化は少ない。評価は、時刻 $\tau$ で学習した後に次の時刻の標本でテストし、変化が起きた時刻を平均から除く。そのため、論文の数値には変化の直後の損失がほとんど入らない。本実装の評価は逐次（ラベルを見る前に予測する）で、この違いは[FedDriftとの対応](../experiments/differences-from-feddrift.md)のD12に記録済み。
- 論文: 5章の主な結果に、この内訳（SINE2・間隔500）とFedDriftの論文の評価との違いを1文で書いた（論文側`ja/sections/05-experiments.tex`、2026-11-01）。
