# LEGACY-003: 実験終端でFedSDA FIFO末尾を確定しない

## 状態と対象

2026-10-04、旧commit748c3aaのexperiment.py終端処理とclients/fedsda.py/BaseClientを調査して確認。状態は改善案・未採用。担当はrun終端の学習/帰属方針、修正specは未作成。

## 観測

終端は未完了の候補sessionを回収し、flushを持つFedDriftの残batchを処理する。FedSDAにはFIFO終端flushがなく、通常の容量内のFIFO末尾は残る。flush_pending_updatesは保留学習回数の消化で、FIFO解放ではない。

## 影響と判断が必要な点

末尾標本は既に予測・監視済みでも学習storeへの帰属が未確定となり得る。これを検知遅延の仕様として残すか、最終モデルへの学習に含めるかは別の設計判断。不具合と断定しない。
過去実験の未帰属標本数・評価/計算量への影響は未確認。終端flushを追加すると学習件数・モデル状態・計算量が変わる可能性がある。

## 今回の扱いと検証

新FIFO部品は明示的な全件取出しを備えても、自動的な終端消費を行わない。現在の移植では旧runの終端方針を変更しない。
採用判断前に通常終端/候補pending終端/警報直後の残FIFOと候補held_dataを別々に記録し、重複や欠落を確認する。変更するなら終端後の学習・評価時機も明示し、旧11/最終3goldenと研究指標への影響を確認する。採用案・修正commit・検証結果は未定。
