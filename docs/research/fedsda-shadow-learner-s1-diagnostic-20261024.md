# S1の影の学習者による成立性診断

2026-10-24。[IMPROVE-030](improvement-candidates/improve-030-split-partially-changed-concept-on-client.md)のS1を試す前段の診断。ユーザーの指示により研究ツールとして実装し、製品のsrc・基準版12・goldenと実際の採用判断は変更しない。specは作らず、本実装を決めた場合にcc-sddへ進む。基点は`186e531b`。先行するE1a/E2の未コミット差分は保持する。

**結論: 長く学ばせれば初期差を取り返す例はあるが、採用の有効性は未確認。** 修正後の5,000標本・4 seed・8 runは失敗0。SEA4の概念2では24影中8件が概念の変わる前にD>0になった。ただしseed1に6件が集中し、概念0やSINE2でも交差する。S1を棄却する根拠にはならない一方、D>0だけで本実装へ進む証拠にもならない。次は研究ツールで採用を試す場合にも、無変化対照と学習手順の対照を先に用意し、過剰な分離と精度低下を測る必要がある。

## 問いと測り方

既存の診断では、SEA4の概念2の警報で、新しいモデルが現在のモデルに約4〜6 nats負けていた。短い保留区間で負けた学習者をその後も学ばせると、初期の不利を取り返せるかを測る。今回は影を予測・帰属・採用に使わない。

- 実際に処理された警報で、最小記述長の選択が`current_model`だった場合に影を作る。抑制された警報では作らない。
- 元の判定が計算した全候補から、新しいモデルの仮説として最短の区間長・学習者を選ぶ。同点なら短い区間長。区間前半の現在のモデルの損失、切り替えの符号長、学習者の選択の符号長を含め、製品と同じ加算順で比較する。
- 元の予測的符号長の計算から、その学習者とoptimizerの学習後の状態を保持する。再学習で作り直さず、Adam等の状態も継続する。
- 初期値はD₀＝L_current−L_new（0以下）。次の標本から、製品の予測後・学習前に、現在の学習用分類器と影の対数損失を求め、Dへ「現在−影」を足す。その後に影だけを1回学ぶ。共有部は影を作った時点の写しで固定し、概念固有部だけ学ぶ。
- Dが初めて0を超える位置を記録する。ただし採用はせず、診断を継続する。期限は240標本（2T）。新たなcurrentの警報では古い影を終えて作り直し、held/newの警報では終了する。run末も終了理由を記録する。
- 真の概念IDは、警報時の区間・その後の軌跡の分類にだけ使う。生成条件・更新・終了・交差判定には使わない。「開始時の概念が変わらないうちに0を超えたか」を区別する。
- 窓内で真の概念が単一でも、以前の変化への遅れた反応である可能性があるため、その区分をそのまま「誤警報」と断定しない。警報による作り直し・run末で未到達の軌跡は打切りとして扱う。

これは既定のモデルの学習経路を固定した診断である。実際に影を採用した後の精度や、サーバ統合後に概念2のモデルが残るかは測っていない。逐次検定の理論保証も主張しない。

### 候補が無い短い保留窓の境界条件

5,000標本への初回拡張は5 run成功・3 run失敗。保留窓が刻みより短いと、製品の選択では新モデルの候補が空になり、currentを選んだ後に警報が抑制される。この正当な呼出しを診断が観測した時点でmin(空集合)を呼んでいた。製品の不具合ではなく診断側の境界条件の漏れ。候補なしはNoneとして返し、影を新設・作り直さず元の処理へ戻す形に修正した。製品の純粋な選択が2標本・刻み5でcurrentを返すことと、抑制/処理済みのコールバックの双方で影を作らないことを2検証で追加し成功。関連検証は55 passed / 2 deselected（2.46秒）、Ruff成功。

修正後の独立LunaレビューもPASS（session `01a16a1b-bf46-76f1-af75-2cf57351993d`、medium、読取りのみ、独立試験は未実施）。初回の5成功と3失敗は保持し、修正前ソースのsnapshotはreview promptから復元してSHA-256一致を確認した。最終比較は修正後の別出力先`20261024_s1-feasibility-fixed-n5000`で全8 runを取り直す。

### 判断と残る問い

1. 「短い窓では負けるが、その後の学習で取り返す」というS1の前提は、一部の概念2の影では成立した。E1a/E2と同じ理由で直ちに打ち切る結果ではない。
2. D>0は概念2に固有ではない。概念0の8/77、SINE2の10/24も、誤採用と確定したものではないが、分離したくない場面での採用を調べる必要を示す。今回、専用の無変化データは実行していない。
3. 影は毎標本すぐにオンライン学習し、共有部を固定する。現在のモデルは保留・まとめ学習や共有部の更新を含むため、差には新概念への適応以外に学習手順の違いも入り得る。この影響は未分離。現在のモデルから同じ手順で継続する対照を設けたい。
4. 次の研究では、無変化対照と上記の学習手順の対照を用意してから、D>0で採用する研究用変種を小規模に比較するのが妥当。測るものは全体/概念別精度、分離数、採用後のDの反転、通信・計算、サーバ統合後の保持。今回の観測だけで採用や保護期間の製品実装は決めない。機能を本実装する判断に至った時点でcc-sddへ進む。
