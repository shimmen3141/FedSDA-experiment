# IMPROVE-017. モデル集合の変更時に既存モデル間の重み比を保つ

- 記録日: 2026-10-17。種別: アルゴリズム調整。状態: 保留（単seed試作済み・採否未決）。
- 基準: `9ea1107`、混合予測/FIFO30/共通T120。発見はユーザー依頼の候補検証診断で、実装specは未作成。
- 対象: `methods/fedsda/prediction_combination/fixed_share_weights.py`の`_synchronize_model_pool`。

## 事実と仮説

モデルID集合が変わると、既存の重みも一様に戻り、累積損失分散も0になる。
検証を外すと候補採用と集合変更が増える。保存MNIST40対で、事後的に正解できる出力は増えても、
結合精度は下がる条件がある。重みの忘却は考えられる経路の一つであり、唯一の原因とは未同定。
詳しい数値・対照実験・限界は[診断記録](../fedsda-candidate-validation-diagnosis-20261017.md)を正本とする。

## 案と懸念

追加IDへ通常の一様初期化と同じ合計質量を与え、残りの質量で既存ID間の比を保つ。
削除時は残存IDを再正規化する。まず分散のresetは従来どおりとして、重み比の保持だけを切り分ける。
新IDの質量をさらに小さくする案や分散の保持は別の比較とする。

期待は、不要な候補の追加で良好な既存モデルの選択を忘れないこと。
一方、旧概念への偏りを引き継いで新概念への追従を遅らせる懸念がある。
T120と同期/局所の二者重みの共通性を変更する案ではない。

## 必要な検証と判断

一時実験は候補検証なしで完了。productionの採用決定ではない。
MNIST2・seed0では300標本で検証なし比+0.1667 ppだったが、5000標本・間隔500では−0.008 ppで、
小規模の改善がそのまま広がらなかった。MNIST4・seed0・5000標本も+0.008 ppにとどまる。他seedは未確認。
両データで学習/採用の記録と共有部probe列は同一で、変化は予測と予測由来の計数だけだった。
今回の第一候補にはせず保留する、という主担当の推奨。最終の採否は未決。詳細は診断記録を参照。
集合追加・削除・全入替・初回・集約後replayの契約、クラス別/変化後精度、再訪/初出、モデル数・通信を比べる。
検証あり/なし双方と複数seed・複数データで比較し、結果を見てから許容幅を自動設定しない。
数値・予測・検出・帰属・診断が変わる可能性があり、採る場合は別specと新しい動作基準が必要。
変更commit: なし。
