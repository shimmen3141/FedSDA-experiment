# IMPROVE-001. 警報区間の同率再利用候補で現行モデルを優先する（候補・未検証）

旧記録ID: ALGO-001。2026-10-08に研究バックログから移動し、具体的な改善候補として分類。種別: アルゴリズム調整。旧実装の固定基準: 748c3aa。発見spec: alarm-interval-model-reuse-assessment。選択結果/帰属/予測重みの更新が変わる可能性があり、挙動を維持する整理ではない。

- 記録日: 2026-10-08。対象は旧clients/fedsda.pyの_resolve_drift/_select_reuse_candidate、移植中のalarm-interval-model-reuse-assessment。
- 確認した事実: 警報区間は適合候補の平均損失最小、同率は保有順。将来検証には現行優先の別規則がある。評価期間・役割が違うため、この差だけでは不具合と断定できない。実験による性能差は未測定。
- 変更案: 現行モデルも適合し、その区間平均が最小値と完全一致する場合だけ現行を優先する。現行が不適合または最小でない場合は旧規則を維持する。将来検証の現行優先を丸ごと流用しない。
- 仮説: 不要な学習帰属切替と予測重み再始動を減らせる可能性がある。精度/通信量の向上は未確認。同じ区間平均でも将来の予測や標本別誤りは異なるため、切替抑制が回復を遅らせる可能性がある。同率自体が少なければ効果は小さい。
- 比較条件: まず同率適合かつ現行が後順位となる頻度を調べる。必要なモデル別区間平均が既存rawにない場合は追加診断を別specで定める。旧規則と完全同率現行優先だけを変え、コード基準・データ・規模・seed群・他の固定設定をそろえる。
- 指標/採否: 切替/重み再始動数、prequential精度/損失、ドリフト後回復、検出誤り、モデル数、計算/通信量。切替だけ減って精度/回復が悪化するなら採用しない。数値の許容悪化量・seed群は実験前に決める（現時点では未定）。
- 拡張: 「ほぼ同率」の許容幅は追加ハイパーパラメータになるため完全同率案とは別に検証する。今回の案へ混ぜない。
- 現在の扱い: 未採用/未検証。リファクタリングでは旧の保有順を維持する。実装する場合は設定/診断/回帰基準/再実験の範囲を別specで承認する。
