# IMPROVE-032: 新しいモデルの仮説の予測的符号長を、新しい方から1本の流れで測り、変化区間を1件刻みにする

- 日付: 2026-10-29（ユーザーの指摘から）。状態: 未検証・未採用。手元の研究ツールで機能を確かめる（下の「検証の計画」）。
- 対象: 警報の後の最小記述長（MDL）による変化点と帰属先の選択（`runtime/alarm_interval_minimum_description_length_selection.py`の`select_alarm_interval_assignment`、`methods/fedsda/training_data_assignment/minimum_description_length_assignment_selection.py`、`learning/training/prequential_code_length.py`）。[モデル再利用の文書](../../components/model-reuse.md#最小記述長の原理による選択既定)。

## 今の扱い（基準版15）
- 変化区間の長さkは、最小変化区間（既定5件）の倍数で、Wの長さ（最大31件）以下の全部を試す。
- 「変化点τで新しいモデルへ」の仮説は、kごとに、末尾k件を、測定用の学習者（固有部を初期化し直した学習者と、現行モデルの写しのwarm start）で、古い方から順に「予測→対数損失を足す→1回更新」して予測的符号長を測る。kごとに学習を一からやり直す。
- 1つの学習者の更新回数は、Wが31件のとき 5+10+…+30 = 105回。1件刻みにすると 1+2+…+31 = 496回（約4.7倍）になる。

## 案
- 区間の中の符号化の順序を「新しい方から古い方へ」と決める。警報の標本から始め、1件ずつ古い方へ足しながら「予測→対数損失を足す→1回更新」を1本の流れで行う。流れの途中までの和が、そのまま各kの符号長になる（k+1件の符号長＝k件の符号長＋次に古い1件の損失）。
- 1つの学習者の更新回数はWの件数（最大31回）で、今の5件刻み（105回）より少ないまま、1件刻みにできる。
- 根拠: MDLの符号長に必要なのは、符号化の順序が受け手にも分かる形で決まっていることで、時間の順である必要はない。同じ概念の中で標本が同じ分布に従う（交換可能）なら、前からでも後ろからでも、符号長の期待値は同じ。
- kごとの符号長が同じ1本の流れから出るので、kどうしの差のゆらぎが、kごとに別々に学習する今より小さくなると期待する（未確認）。

## 懸念
- 区間の中で分布が徐々に変わる場合は、順序で値が変わる（前からでも後ろからでも近似）。
- 1件刻みにすると変化点の候補が約5倍に増える。今の切替の符号長（−ln(1/T)＋ln(行き先の数＋1)）には変化点の位置を表す項がなく、候補が多いほど偶然に短い仮説が選ばれやすくなる。位置の項（例: ln(kの候補の数)）を足すかを比べる。
- 符号長の値が変わるので、選ばれる変化点・帰属先が変わり、既定にするなら基準版が上がる。最小変化区間（5件）は、件数不足で警報を保留する判定にも使うので、刻みとは別に残す。
- 締め切り（PAKDD 2027、2026-11-20）の前には既定を変えない（2026-10-29の判断）。

## 検証の計画（手元、研究ツール）
- 変種（製品の既定＝基準版15の上）:
  - 既定: 今の扱い（古い方から、kごとに一から、5件刻み）。
  - R5: 新しい方からの1本の流れ、5件刻み（順序の違いだけを分ける）。
  - R1: 新しい方からの1本の流れ、1件刻み（最小は5件のまま）、位置の項なし。
  - R1＋位置: R1に、切替の仮説の符号長へ ln(kの候補の数) を足す。
- 条件: MDLの選択が効くデータ（MNIST4、SINE2、SEA4、CIRCLE2）、集約間隔50・200、seed 0〜3、10 client×5000標本。手元の機能確認で、採否の判断には使わない。
- 見るもの: 全体の累積精度（既定との同じseedの対の差）、警報の回数、MDLの選択の内訳（現在のまま・再利用・新しいモデル、選んだkの分布）、測定用学習者の更新回数（計算量）。
